# 数据保护、书签验证与面板适配

日期：2026-10-23。基线：最新主线 `64853d09ab10cf4bb996f534fe3550c2de976903`。
工作分支：`codex/reliability-adaptive-20261023`。范围：macOS。

## 完成内容

1. **任务迁移与历史保留**：只有目标缺失时才复制可解码的旧记录；旧偏好键保留为迁移时的回退快照。已有或损坏的目标不被覆盖，写入失败时保持错误保护，显式重试后才能继续。取消超过200条就截断历史的逻辑，旧任务及网页/文件/笔记快照仍能访问和编辑。
2. **书签验证**：移除将任意创建异常转成跳过的处理。新增独立签名辅助程序，使用真实生产 GIF 读取代码，在两个独立进程间创建、恢复同一书签，并验证五种错误数据拒绝。普通测试仍直接调用书签 API；出现错误会失败，而非隐藏错误。
3. **面板适配**：在主线面板上整合，概览先显示组件，最近/当前任务位于下方。默认开启自动高度；800pt下三个组件一排，四组件2×2，窄宽自动换列；超屏幕或手动上限时正文滚动，标题与导航固定。手动200pt保留为可选设置。
4. **窗口与状态保护**：按内容自然高度测量，过滤旧宽度/旧页面结果及无效尺寸；合并窗口更新。换列保留组件身份。跨屏几何约束考虑屏幕原点和侧边Dock，同屏分辨率变化刷新缓存。

保留主线的工具导航、详情页、快捷键、网页链接编辑、玻璃背景、封面配色、图标与展开收起动效。验证清单中8个对应模块与基线逐字节一致；窗口和面板接入处另经静态审查与回归测试。

## 实际组件渲染

渲染使用生产 `ExpandedPanelView` 和真实工具视图，数据、偏好、日历读取均来自临时夹具。DEBUG几何报告默认关闭，仅在测试时开启；Release不编译几何读取，测试同时以原生滚动视口和文本编辑器边界交叉验证。

| 场景 | 结果 |
| --- | --- |
| 媒体/日历/托盘 + 3条历史 | 800×438pt，组件一排，任务区完整位于下方 |
| 四组件 + 5条历史 | 800×776pt，两行两列 |
| 窄320pt及160pt退化布局 | 单列，卡片边界在正文内；长文本允许省略 |
| 手动200pt及屏幕190pt | 标题导航固定，滚动能到达最后任务与底部入口 |
| 笔记编辑 | 自然高度不再受244pt卡片裁切；详情编辑区保留240pt（原生视口232pt加上下内边距8pt） |
| 托盘6文件 | 概览4行与全部入口、详情6行均有实际节点几何验证 |
| 状态保持 | 组件网格换列再恢复，状态标识保持一致 |
| 中英文/明暗 | 三组件场景四种组合均验证 |

离屏环境没有暴露SwiftUI虚拟辅助功能节点，因此未将空AX树当作产品缺陷或跳过验证；改用真实视图节点的DEBUG几何报告。该渲染验证布局，不代表玻璃材质、触控板手感或真实跨屏动画已验收。
