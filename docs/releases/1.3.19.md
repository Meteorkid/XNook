# X Nook v1.3.19

发布日期：2026-10-22

本版加入任务网页链接的保存与编辑，并保留 v1.3.18 的双岛切换修复及经典面板默认尺寸。

## 新增

- 为正在进行的任务和最近任务记录增加了网页链接入口，点击任务标题即可打开。
- 支持添加 HTTP/HTTPS 网页、设置标题、交给默认浏览器打开，以及解除关联；每个任务最多保存 20 项。
- 增加了已保存链接的标题和地址编辑，保存后保留原来的列表位置；取消编辑保持原内容。

## 可靠性

- 检测重复地址和过期的编辑内容，避免覆盖其他操作已经保存的新值。
- 保存失败时保留输入，并提供重新读取入口；无法读取的旧任务数据会保留并阻止继续覆盖。
- 链接详情打开时暂停面板自动收起，编辑期间先保存或取消再关闭；显式双岛切换继续按原流程处理。
- 兼容旧任务记录，已结束任务的链接也可以继续维护。

## 使用方式

1. 展开 X Nook，点击当前任务标题或最近任务记录。
2. 在“网页链接”中输入地址和可选标题，点击“添加链接”。
3. 已保存链接可选择“打开”“编辑链接”或“解除关联”。

## 安装与验证

- 安装包：`XNook-1.3.19.dmg`，Apple Silicon（arm64），macOS 14 或更高版本。
- 使用与上一版相同的 ad-hoc 本地签名，签名完整性已验证；尚未使用 Developer ID 签名或 Apple 公证。
- 发布源码的完整测试：**256 项通过，0 失败，0 跳过**，其中链接回归 38 项、会话回归 19 项。
- Release 构建、DMG 完整性、包内应用签名及逐文件哈希比对通过；中英文明暗的编辑、历史和写失败界面已离屏检查。
- 最终安装包未在本轮替换到本机；实际键盘、VoiceOver、编辑期间强制切岛后的原生弹窗恢复、多屏与睡眠唤醒仍未验收。离屏渲染不能替代这些交互验证。
