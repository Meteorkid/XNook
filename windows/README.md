# Windows XNook

XNook 的独立 Windows 客户端，沿用媒体、日历、笔记、文件架与 NookFlow 工作流，并支持切换到配套 Windows XIsland。

## 0.3.2 安全、保存与恢复补丁

- 日历解析进入可终止 Worker，跨来源共享输入、组件、输出和计算预算；不可满足的重复规则超时终止，坏刷新保留旧缓存。
- 歌词标签按线性路径解析，限制展开后的正文总量；单个超额候选不阻断其他合法候选。
- 右键和托盘退出统一原生状态机，保存失败支持取消、重试和明确放弃。
- 播放器选择与设置按顺序提交；超容量的任务/导入等操作保持原状态，可确认删除历史释放容量，不删除源笔记或文件。
- 同时到期日程批量提醒，声音成功后统一去重；慢磁盘仅保留在途和最新待写快照。
- 隐藏界面停止歌词DOM更新；GIF坏条目不再阻塞全库，删除通过原子移出与可重试清理恢复。

验证与剩余实机门禁见 [执行结果](../docs/reviews/2026-10-18-execution-results.md)，阶段计划见 [执行路线](../docs/reviews/2026-10-18-execution-roadmap.md)。本地构建不会自动替换正在运行的正式版。

## 0.3.1 工作流与紧凑布局对齐

- 概览直接开始/结束任务、操作所选播放器、新建/打开最近笔记和常用文件。
- 全部任务历史分页和详情，保留真实开始/结束时间及关联资料；恢复笔记后不重复创建副本。
- 日历概览按所选日展示，今天过滤已结束，详情显示完整日程、状态和来源颜色；月历覆盖跨日和边缘日期。
- 同曲歌词断网后持续退避恢复，播放倍速参与歌词时轴；默认波形跟随播放，暂停和减少动态时停止动画。
- 文件逐项检查可访问性和大小，坏项不影响其他文件，支持刷新重试并保留引用。
- 收起药丸支持横向拖动、向下拖动展开及右键菜单；展开横滚不切换应用。托盘可直接打开设置或检查更新。
- 面板高度按内容收缩，设置值作为上限；长按新建快捷键不会生成多篇空笔记。
- 尺寸下限对齐 Mac：普通药丸40×8、歌词药丸60×10、面板160×160；窄面板使用下拉导航，极矮药丸保留可点击细条，右键菜单临时扩展宿主窗口。
- 同曲时长小于1秒的波动可复用已匹配歌词，仍按精确时长重新校验候选，避免错误版本混入。

本轮仍未取得 Windows 实机结果；完整证据见 [0.3.1 验证报告](../docs/windows/parity-verification-0.3.1.md)。

## 0.2.0 已有功能

- 深色、浅色和系统主题，中英文界面，面板与浮岛尺寸、工具开关和历史条数设置。
- GIF 导入与选择、果冻和磁吸效果、收起时的歌词滚动；支持减少动态效果。
- 悬停展开、移出和空闲收起、纵向手势；编辑笔记、输入法组合和对话框期间保护当前操作。
- 文件复制到系统剪贴板、拖出到其他应用；点击音乐封面打开对应播放器。
- 本地 ICS 自动刷新、提前提醒音和勿扰时段；歌词磁盘缓存、检索回退和失败重试。
- 损坏数据先备份再恢复，可查看刚生成的备份；开机启动、检查 Windows 更新并打开发布页。
- 与 XIsland 共享横向手势开关、灵敏度和启动显示偏好；首个应用冷启动、显式托盘显示和迟到启动任务也经过显示权协调。

以上已实现并在本机进行单元、协议与受控浏览器测试，Windows 实机运行仍需验收。跨虚拟桌面驻留仅在 Windows 11 24H2 build 26100.2605 或更新版本启用；系统不支持时明确报错并回滚开关。

## 播放器选择

打开网易云音乐或 QQ 音乐并播放一首歌，再进入 XNook 的“音乐”页，从“播放器”下拉框选择来源。

- 自动选择优先正在播放的网易云/QQ 音乐；同优先级先考虑系统当前来源，再保留已有来源。
- 手动选择会保存并在重启后恢复。选中的播放器退出时保留选择并提示离线，可使用“回到自动选择”。
- 播放、暂停、上下首及跳转均绑定界面显示的来源，不向其他播放器发送全局媒体按键。
- 同一应用有多个会话时按应用分组；首版不提供浏览器标签选择。
- 如果列表里没有该播放器，先开始播放并确认客户端支持 Windows 系统媒体控制。当前版本不安装第三方插件，也不通过窗口标题猜测曲目或进度。

QQ 官方下载页的 22.7.6 和网易官方下载入口已核对，但 XNook 在两款最新版上的真机控制、进度和歌词同步仍需验证。证据和具体边界见 [兼容性核查](../docs/windows/music-compatibility-2026-10-17.md)。

## 本地构建

目标为 Windows x64（系统媒体接口要求 Windows 10 1809 或更高版本）。构建需要 Node.js 22、Rust 1.89 或更高版本的 MSVC 工具链、Microsoft C++ Build Tools（桌面 C++ 工作负载）和 WebView2。依赖仅安装在此子项目。Windows 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

开发运行：

```sh
npm ci
npm run tauri -- dev
```

浏览器预览使用 `npm run dev`，监听 127.0.0.1:1421。预览只验证界面和隔离数据，不能证明原生媒体、文件操作或双应用切换已通过实机验收。

## 约定

- 日历使用用户选择的本地 `.ics` 文件，支持手动和自动刷新；不连接未配置的 Microsoft/Google 账号。ICS 的 VTODO 尚未实现。
- 日历提醒使用声音，不显示系统通知横幅，也不会唤醒休眠中的电脑；勿扰期间跳过提醒。
- 音乐从 Windows 系统媒体会话读取；不同播放器提供的控制与进度能力可能不同。
- 歌词成功结果可在磁盘缓存 30 天，真实空结果短缓存 5 分钟；网络错误不当作无歌词缓存。
- macOS 的安全书签不能直接迁移到 Windows；需要重新选择本机文件。
- XIsland 0.1.3 及更旧 Windows 包不含基本联动；0.1.4 仅支持基本联动。共享设置须使用包含新偏好协议的版本，优先使用完整测试包中的配套安装器。
- 不自动提交 Git、推送、发布或修改全局工具配置。

联动首次使用须将两个新版应用各启动一次，登记安装路径。之后可以启动尚未运行的对方。托盘显示、重复启动、退出和全屏恢复使用同一显示权协议，见 [协议说明](../docs/windows/island-link-v1.md)。

笔记保存失败时默认保留编辑内容，并提供重试或明确放弃后退出。若界面本身未加载或失去响应，再次点击托盘退出会显示原生确认；只有明确选择强制退出才会绕过保存。
