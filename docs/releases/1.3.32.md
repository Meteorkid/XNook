# X Nook v1.3.32

发布日期：2026-11-17

本版在 v1.3.31 的基础上，补齐实时字幕的证据链能力，并修复安装包签名配置导致的系统授权重置问题。媒体接入与来源锁定功能沿用 v1.3.31。

## 实时字幕

- 新增画面文字证据源：按需截取画面、裁切底部区域后在本机做 OCR，按区间执行且不占用连续音频预算；连续失败会自动停手。
- 证据链按预算裁剪来源：预算收紧时优先保留高等级证据，低等级来源被跳过；provider 的可用性纳入选源，避免无歌词时占用预算挤掉识别。
- 新增歌词证据源及配套的时间轴对齐、跳变检测；设置页可查看预算、证书数、当前等级与各来源的执行/跳过计数。

## 可靠性

- **所有发布构建启用 Hardened Runtime**。此前构建脚本默认关闭该选项，导致 v1.3.31 首次发布的签名标志与既有版本不同，macOS 将其视为不同应用而重置日历、自动化等系统授权。本版恢复与 v1.3.30 一致的签名身份（`adhoc,runtime`），后续更新可正常继承已授予的权限。
- 媒体快照改为串行读取前后两次 PID，播放器切换瞬间不再出现标题与来源错配。

## 验证与安装包

- 安装包：`XNook-1.3.32.dmg`，Apple Silicon（arm64），macOS 14 或更高版本。
- 延续 ad-hoc 本地签名并启用 Hardened Runtime；尚未使用 Developer ID 签名或 Apple 公证。
- 发布前全量测试：XNook **1305 项，101 项条件跳过，1 项环境性失败**（`GifResourceTests` 的书签用例需要独立签名宿主，本机 SwiftPM 沙箱不可用），授权核心与发码核心全部通过。该失败在远端主线上同样存在，与本次功能改动无关。
- 签名身份、`SoftwareLicensePublicKey` 注入与 app 权限描述均在打包脚本中校验通过。
