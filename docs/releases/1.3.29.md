# X Nook v1.3.29 — 日历滚动与系统权限状态修复

日期：2026-10-30

本版为概览日历补齐了原生横向滚动，并修复了日历、播放器自动化和登录项的权限状态显示。建议使用日历与媒体功能的用户更新。

## 日历浏览

- 概览与独立日历共用了原生日期滚动条，可用触控板双指左右浏览日期。
- 保留了左右翻页按钮、3/5/7 天步长和远期日期导航，翻页后日期条会同步定位。
- 修复了滚动停在非整格位置时，界面刷新可能将日期条拉回中心的问题。

## 权限与设置

- 补齐了安装包所需的日历签名声明，并增加了打包检查，避免缺少必要权限声明的安装包继续生成。
- 自动化权限改为分别显示 Apple Music 与 Spotify 的状态，刷新时只查询已运行的播放器，不会启动播放器或弹出授权请求。
- 登录项开关与状态说明统一跟随系统设置，修改失败时会保留实际状态并显示原因。
- 日历权限变化后，设置页会刷新授权状态，继续区分完全访问、仅写入、拒绝和受限等情况。

升级后若系统重新询问日历访问，请在概览点击“允许读取日历”，并在 macOS 弹窗中确认完全访问；系统确认后，设置页会显示“已允许”。

## 升级兼容

保留了已有任务、待办入口开关、布局方案、媒体氛围、双岛联动、笔记和文件托盘，以及 1.3.28 的软件授权修复；无需重置配置或清空内容。

## 验证与安装包

日历与权限定向回归 **53 项全部通过**；完整回归 **XNook 1228 项，98 条件跳过、0 失败；共享授权核心 31 项，1 条件跳过、0 失败**，详情见[日历与权限验证记录](https://github.com/Meteorkid/XNook/blob/v1.3.29/docs/verification/2026-10-30-calendar-permissions.md)。这些自动化结果不包含真实 TCC 授权回读或物理双指操作验收。

安装包为 Apple Silicon **arm64**，最低 macOS **14**，沿用现有安装包的 **ad-hoc 签名与 Hardened Runtime**，未使用 Developer ID 或 Apple 公证。
