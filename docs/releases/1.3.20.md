# X Nook v1.3.20

日期：2026-10-24

本版加入原生网格布局编辑器，让媒体、日历、笔记、文件托盘、当前任务和最近任务都能独立安排位置与大小，并重新整理了默认概览的排版。

相对 v1.3.19，本版同时发布了此前已合入主分支的完整笔记与任务工作流、日历刷新、面板自动适配、媒体与 GIF 优化，以及设置窗口修复。

## 新增：自己安排六个模块

- 增加了原生布局编辑器，可从概览右侧的布局图标或设置中的“打开布局编辑器”进入。
- 支持拖动模块标题调整位置、拖动右下角调整大小，释放后自动吸附网格并让其他模块避让。
- 提供了三分之一、二分之一、三分之二和整行四种宽度，以及分档高度、显示开关和无需拖拽的前移／后移操作。
- 将当前任务与最近任务拆成了独立模块，可分别决定位置、大小和是否显示。
- 增加了布局草稿、保存、取消与恢复默认，只有点击“保存”或按 ⌘S 才会写入布局。
- 在窄窗口中自动折成两列或一列，并保留原先保存的桌面排列，恢复宽窗口后可继续使用。
- 隐藏模块后收拢了可见内容的空行，调整布局不会删除笔记、文件或任务记录。
- 沿用了升级前的组件与最近任务显示开关，并让设置页和布局编辑器共享同一份配置。
- 编辑布局时暂停了自动收起并固定编辑视口，避免拖动过程中面板高度跟着变化。
- 增加了布局保存冲突提示和异常配置保护，恢复损坏或较新版本的布局前会保留原始配置副本。

## 改进：默认概览与小卡片

- 将媒体封面、曲目信息和播放控件改成了横向排列，并保留详情入口与既有播放、歌词能力。
- 修复了 160pt 极窄面板中媒体卡片被播放按钮撑宽的问题，小尺寸改为上下两行，封面与按钮保持可用尺寸。
- 统一了媒体、日历、笔记和文件托盘的标题区域、边距与卡片高度。
- 将日历概览改为按宽度展示完整的 3、5 或 7 个日期，消除了日期条两端只露半格的问题。
- 修复了日历缩放时改变所选日期或吞掉第一下横向滚动的问题，详情仍可通过滚动选择日期。
- 缩紧了日历权限提示和空态，首次授权仍由用户点击按钮发起。
- 让笔记、文件托盘和最近任务按卡片高度减少展示行数，并保留“查看全部”入口。
- 在最小文件托盘卡片中保留了一行文件与全部入口，概览文字保持至少 11pt。
- 保留了笔记的当前编辑状态，返回小尺寸概览后仍可进入详情继续编辑。

## 新增与改进：笔记、任务、日历和文件

### 笔记

- 增加了全部笔记列表、标题与正文搜索、重命名、删除撤销，以及 Markdown／TXT 原文导出。
- 将编辑内容即时保留在内存中，并在切换笔记、关闭编辑器和正常退出时完成待保存内容。
- 保存失败时保留了草稿并显示提示，正常退出时可返回继续处理未保存内容。
- 读取或解码失败时保留了原文件，提供重试和“保留原件并恢复”入口，恢复前先保存副本并重新尝试读取。

### NookFlow 任务与历史

- 增加了手动输入任务名称并开始的入口，也可继续从日历事件开始任务。
- 增加了最近任务与全部历史详情，可重新打开关联笔记、文件和已有网页链接。
- 为新关联文件保存了独立引用，清理文件托盘后仍可从任务访问原文件，旧记录则继续尝试使用托盘中的引用。
- 将批量关联文件改成了一次保存，减少关联多份资料时的重复写入。
- 加强了任务保存失败与重复附件的处理，写入失败时保留原状态，避免界面显示尚未保存的结果。
- 将任务历史迁入独立存储并保留旧数据的迁移快照，已有或无法读取的新存储不会被旧数据覆盖。
- 取消了超过 200 条时截断历史的行为，完整记录及其网页、笔记和文件关联继续保留，概览显示条数只影响界面。

### 日历与文件托盘

- 让日历概览优先展示进行中和未来日程，详情继续保留所选日期的全部安排。
- 在系统日历变化、应用返回前台、跨日和时区变化时刷新日程，并在浏览其他日期时保留选择。
- 区分了未授权、未选择日历、当天没有日程和当天日程全部结束等状态，详情可打开系统日历。
- 保留了暂时无法解析或磁盘离线的文件记录，后续增删和书签刷新不会悄悄清除这些条目。
- 为文件读取、保存和暂不可用状态增加了明确提示与重试入口，保存失败会说明本次更改未生效。

## 改进：面板、键盘与设置

- 增加了概览与工具详情导航，默认按内容自动调整面板高度，超过屏幕或手动上限时保留正文滚动与固定标题导航。
- 保留了手动高度上限，并改进了窄窗口、屏幕原点、侧边 Dock 和同屏分辨率变化时的窗口几何约束。
- 修复了组件换列、工具切换和退出布局编辑时的旧尺寸测量干扰，保留组件状态并减少面板高度跳动。
- 修复了展开面板拖动窗口的逻辑抢走文字拖选、文件拖出和原生按钮交互的问题。
- 增加了面板内的 ⌘0 返回概览、⌘1–4 切换工具、⌘N 新建笔记和 Esc 返回／收起，同时保留文字编辑器自身的撤销操作。
- 统一了菜单、面板按钮和 ⌘, 打开的设置窗口，修复了重启后恢复空白设置场景及重复窗口的问题。
- 为顶部物理刘海预留了按钮避让区域，无刘海屏幕继续使用正常布局。

## 改进：外观、动效与稳定性

- 增加了专辑封面取色，让媒体控件和封面阴影随曲目配色变化，无法取色时回退系统强调色。
- 在 macOS 26 深色模式启用了 Liquid Glass 并增加文字背衬，浅色模式及 macOS 14／15 继续使用纯色背景。
- 统一了间距、圆角与字号，并调整了展开和收起的弹簧表现，动效参数会按屏幕宽度选择档位。
- 增加了图标悬停、按下与扫出反馈，并让系统或应用的“减少动态效果”设置覆盖装饰动画、GIF、滚动文字和日历日期条。
- 修复了自动收起倒计时在悬停后重新计算整个延迟的问题，离开面板后继续等待剩余时间。
- 减少了重复自动收起任务与未变化鼠标状态引起的界面重算，并修复了旧延迟回调重新展开面板的问题。
- 增加了收起动画的超时收尾保护，避免动画回调中断后面板一直停留在展开状态。
- 在 GIF 暂停或不可见时停止刷新，修复了重复恢复与切换资源时的帧时钟状态，并对过大或无效 GIF 给出明确提示。
- 修复了空白歌词或无效同步歌词候选阻断后续搜索的问题，并在播放器暂停时优先保留有曲目信息的播放源。
- 加强了共享数据的单实例保护和双岛显示权锁的超时处理，避免多个副本同时写入数据或因另一进程持锁而卡住启动。

## 使用方式

1. 展开概览，点击导航右侧的布局编辑图标。
2. 拖动标题调整位置、拖动右下角调整大小，或用工具栏选择模块和尺寸。
3. 点击“保存”或按 ⌘S 应用布局；点击“取消”放弃本次修改。
4. 需要回到初始排列时，点击“恢复默认”，检查后再保存。

笔记或网页链接仍有未完成的编辑时，先保存或取消原操作再进入布局编辑；更多日常操作见[工作流指南](../WORKFLOWS.md)。
