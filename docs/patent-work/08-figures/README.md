# 08 说明书附图（正式线条图）

## 产物

| 文件 | 说明 |
| --- | --- |
| `说明书附图.pdf` | 合并稿，8 页 A4 竖向，每图一页，随申请文件提交 |
| `figs/fig1.pdf` … `fig8.pdf` | 单页稿，便于代理师单图替换或重排 |

| `figs_b.py` | 图 5–图 8 |

## 重新生成

```bash

for i in 1 2 3 4 5 6 7 8; do \
  sips -s format png --resampleWidth 1400 figs/fig$i.pdf --out png/fig$i.png; done
```

`qlmanage` 在本机沙箱下不可用（Operation not permitted），转位图用 `sips`。

## 制图规范对照

| 要求 | 本稿做法 |
| --- | --- |
| 黑白线条，不得有灰度、阴影、彩色 | 只用 stroke，不填充；线条统一 0.35 mm |
| 附图周围留边 | 版心 210×297 mm，四边留 22 mm |
| 图中只出现必要词语 | 仅模块名、参数符号、区间标号、附图标记 |
| 附图标记用阿拉伯数字 | 图 1 用 1–12，图 8 用 1–6，与说明书正文的模块名一一对应 |
| 附图内不重复图题 | 每页只标「图 N」，图题放在说明书「附图说明」 |
| 字体可读、缩小后仍清晰 | 正文 6.0–6.8 pt，状态名 9 pt；缩至 2/3 仍可辨 |

## 与权利要求的对应（核对口径）

- **图 1**：12 个附图标记对应要素清单 ①–⑫；其中 7 为「易变／已稳定」两态，已读为独立判定量。
- **图 2**：六层证据链的顺序**必须**与权 3 一致（文本流 → 既有全文强制对齐 → 媒体元数据 → 画面文字识别 → 本地已转写缓存 → 流式识别）。
- **图 5**：只有「易变 → 已稳定」一条状态转移；已读用虚线框表示，**不是第三态**。
- **图 8**：模块 1–6 **必须**与权 13 的六个模块逐一对应，不得增减；实体表维护并入模块 3，不单独设框。

## 尚未满足提交要求的两点

1. 正式电子申请对附图有分辨率与页边距的具体要求，最终以代理机构排版系统为准；本稿提供矢量 PDF，可直接置入。
2. 附图标记若在说明书中被引用（如「模块 3」），正文需与之逐字一致；目前正文用模块名而非编号引用，代理师可自行决定是否加编号引用。
