# 第一轮可靠性与流畅度优化

## 目标与范围

依据 2026-09-15 优化评估及用户“开始定目标，现在执行”的授权，本轮先完成四项可独立验证的改动：笔记保存保护、文件架离线记录保留、自动收起任务有界、GIF 刷新生命周期。保留现有文件格式和交互结构，不在本轮重排面板或增加搜索、多选等功能。

## 实现方案

- 笔记：区分文件不存在与读/解码失败，失败时保留原件；草稿立即更新内存，只延迟磁盘写入；切换、关闭编辑器和正常退出时保存待写内容。退出保存失败时默认返回，只有用户明确选择“不保存并退出”才允许放弃。注入存储路径以便测试，失败提供可重试的用户反馈。
- 文件架：不可解析记录跨加载后的新增、移除和书签刷新继续保留；损坏存储不能被静默覆盖。维持已有 bookmark 记录兼容，显示暂不可用数量或存储错误。
- 自动收起：提取一个专用控制器，仅在展开、指针离开且延时开启时保持一个等待任务。指针进入、收起、视图移除时取消；相同状态轮询不重建任务，设置变更重新计时。等待结束后复核指针状态，避免过期结果收起面板。
- GIF：使用明确的主线程刷新生命周期，暂停与不可见时停止，恢复幂等，视图拆卸清理驱动及回调，切换 GIF 重置帧状态。保留 macOS 14 支持，不增加依赖。

## 验收

1. 隔离临时目录测试覆盖笔记损坏原件保护、跨笔记防抖保存、关闭与 flush、保存失败反馈和恢复。
2. 文件架测试覆盖不可解析记录在后续写入后仍存在、损坏文件保留及重试，测试不访问真实文件架。
3. 自动收起测试覆盖重复轮询仅保留一个等待任务、进入取消、离开后触发、设置关闭、延时变更与释放。
4. GIF 测试覆盖暂停、恢复幂等、替换数据、拆卸与旧回调；可见状态由窗口/面板状态共同控制。
5. 全量 `swift test` 和 `git diff --check` 通过。性能收益以消除明确的无效任务与刷新为限，不宣称未经 Instruments 测量的 CPU/帧率提升。

## 执行与交付

四个模块并行实施，主代理负责自动收起、视图与退出集成及统一构建测试。更新 CHANGELOG 的未发布项和 Obsidian 总结。保留用户已有工作区改动；完成后询问是否提交，不自动执行 git add/commit。
