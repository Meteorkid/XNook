## 三、四个踩过的坑，改参数前必须知道

1. **正文字体必须是 `Songti SC` 而不能只设 CJK 字体。**
   只写 `-V CJKmainfont` 时，拉丁与符号部分落到 LaTeX 默认的 `lmroman`，
   而它没有 `≈ ≠ ≤ ≥ ∈ ∩ ∪ ∂ ⌈ ⌉ ⌊ ⌋ …` 与希腊字母，XeTeX **静默丢字**（不报错，PDF 里就是空白）。
   实测：只设 CJK 字体时，说明书有 21 个字符被吞。现 `build.py` 的 `check_glyphs()`
   把 "Missing character" 升级为硬失败，出现即拒绝出 PDF。
2. **`\includegraphics` 需要 `graphicx`。** pandoc 只在文档含图片时才加载它；
   摘要附图是用原生 LaTeX 居中环境嵌入的，pandoc 看不见图片，故 `header.tex` 显式加载。
3. **字号直接决定要不要交超页费。** 超页费按「说明书（**包括附图**）」合计页数算，第 31 页起每页 50 元，
   且**不属可减缴范围**。同一份文字：小四（12pt）＝说明书 32 页、五号（10.5pt）＝23 页，差 450 元。
   现取五号：字高约 3.7 mm，落在指南第一部分第一章 5 要求的 3.5–4.5 mm 内；行距按 1.5 倍。
   改 `fontsize` 前先算页数，别只图好看。
4. **母本里的 `---` 分隔线会在 PDF 里变成横线。** `extract.py` 原先只删末尾的，权 7 与权 8 之间那条
   漏进了正文，渲染成一条无故横线。现已改为删除权利要求块内全部独占一行的 `---`。

另有三处字符在宋体中确实不存在，已在 `extract.py` 中改写（详见 `转换记录.md`）：
取整符号 `⌈T/W⌉`→`ceil(T/W)`、`⌊t/W⌋`→`floor(t/W)`（共 5 处），
`level＝5…1`→`level＝5 至 1`（2 处）。含义不变。
