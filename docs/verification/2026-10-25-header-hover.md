# 面板头部按钮悬停修复

日期：2026-10-25。用户要求设置和关闭按钮采用正常的放大、凸起反馈，去除鼠标经过时的黑影闪烁。

本页保留早期独立按钮候选的验证身份；修复现已整合进 [面板高度与布局编辑](2026-10-25-panel-sizing-editor-overhaul.md) 的 v1.3.23 发布范围，下文“未提交、未安装”描述的是该早期候选阶段。

## 原因与改动

头部按钮原来使用 `MotionIcon`：每次进入都会把 `drawProgress` 置为 0，再用 0.42 秒重新扫出图标，因此短暂露出黑色底板。悬停监听还附在会缩放和位移的图标上。

现在改用独立 `PanelHeaderButton`：外层固定 26×26 点击/悬停区域；内部图标悬停放大 1.08 倍、上移 1 pt，按下缩小至 0.94 倍，使用短 easeOut。没有遮罩、绘制重播、呼吸或按钮阴影。减少动态效果时关闭缩放、位移和动画。原帮助文字、无障碍名称及业务回调保留；同排布局按钮使用相同样式。
