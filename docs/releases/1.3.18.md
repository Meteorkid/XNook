# X Nook v1.3.18

发布日期：2026-10-22

本版改善 X Nook 与 X Island 之间的切换可靠性，并将面板默认最大高度调整为 200pt。

## 双岛切换

- **确认目标显示后再隐藏来源岛。** 修复了打开目标应用成功但目标岛尚未出现时，来源岛已经隐藏的问题；现在以目标应用的可见岛窗口作为切换完成条件。
- **失败时保留可用入口。** 目标启动失败、未显示窗口，或系统打开回调没有返回时，8 秒超时会结束当前请求并保留或恢复来源岛，随后可再次切换。
- **补齐冷启动显示请求。** 目标 App 尚未创建窗口时收到的显示指令会保留到初始化完成，减少首次启动时没有显示岛的情况。
- **首次使用即可识别联动能力。** 已安装的目标应用通过安装包中的身份和 URL 协议声明进行识别，旧协议登记不再让尚未启动过的目标被禁用。
- **正确区分设置窗口与岛窗口。** 显示确认按目标 App 的进程、精确窗口层级和可见状态检查，避免把 X Island 的设置窗口当作岛已经出现。
- **旧请求不覆盖新操作。** 重复手势不会重复发起同一切换，过期的隐藏通知和迟到的完成回调不会再次隐藏用户刚显示的岛。
- **减少全屏与桌面切换竞态。** 手动显示、隐藏和双岛切换会作废之前的异步全屏判断，防止旧结果覆盖用户当前操作。
- **启动时保证有可见入口。** 对方应用只在后台运行但没有显示岛时，本应用仍可显示，避免把“进程存在”误认为“岛已显示”。
- **优先使用正式安装的 App。** 打开目标时优先定位 `/Applications` 或用户 `Applications` 中的有效安装，降低构建副本或备份抢占 URL 协议造成的异常。

## 面板尺寸

- 面板默认最大高度从 400pt 调整为 **200pt**，作用于新用户及尚未保存该选项的用户；已有自定义高度会继续保留。
- 内容不足最大高度时仍按实际内容展开，超过上限时继续遵循原有的高度限制。

## 安装与兼容性

- 安装包：`XNook-1.3.18.dmg`，内含 `X Nook.app`。
- 支持 Apple Silicon（arm64），最低系统版本为 macOS 14 Sonoma。
- 建议同时更新到 [X Island 2.0.4](https://github.com/Meteorkid/XIsland/releases/tag/v2.0.4)，以使用本轮两端配套的切换修复。
- App 使用 ad-hoc 本地签名，已验证完整签名；未使用 Apple Developer ID 签名，未经过 Apple 公证。
