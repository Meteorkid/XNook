# X Nook v1.3.30 — 日历连续跨月滚动

日期：2026-10-30

本版修复了 v1.3.29 本机验收中发现的日期范围边界：基本滚动已经可用，但滚动到边缘后无法继续跨月。

## 修复

- 概览与独立日历都支持双指左右连续浏览更早或更晚的日期，接近边缘时会自动补充日期。
- 补充日期时保留原来的画面位置，减少回跳，并控制长时间浏览的资源占用。
- 保留了左右翻页、远期日期、回今天和组件自动适配，以及 v1.3.29 的日历与其他系统权限修复。

## 验证与安装包

定向回归 **35 项全部通过**，覆盖双向纯滚动80天、跨月与跨年、小数位移、视图复用、远期跳转、边缘选日、缩放、回今天和夏令时。完整回归 **XNook 1233 项，101 条件跳过、0 失败；共享授权核心 31 项，1 条件跳过、0 失败**。同一安装包已在本机验收，用户确认连续跨月与放手停留正常；日历权限显示“已允许”，其他原配置已恢复。详细记录见[连续跨月验证](https://github.com/Meteorkid/XNook/blob/v1.3.30/docs/verification/2026-10-30-calendar-continuous-month-scroll.md)。

安装包面向 Apple Silicon **arm64**，最低 macOS **14**，沿用 ad-hoc 签名与 Hardened Runtime，未使用 Developer ID 或 Apple 公证。升级保留待办入口开关、布局、任务、笔记、托盘与软件授权配置。
