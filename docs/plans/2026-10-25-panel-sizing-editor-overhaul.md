# 面板高度与布局编辑体验整修

用户要求修复媒体详情底部空白，并整体改善自定义布局的操作说明。本轮沿用已确认的 Sapphire 横向封面和 TO-DO-Panel 模块边界，直接实现明确的操作流程，不重新设计媒体比例或数据模型。

## 范围

1. 修正父级尺寸/详情变化时无条件清空新测量的问题；通过完整上下文校验保留正确测量，防止窗口持续回退 400pt。
2. 设置中将宽度适配与高度分开：高度选“自动贴合内容”或“自定义高度上限”。新 `panelHeightMode` 字符串未设置时沿用旧 `panelAutoSize` 语义；数值继续使用 `panelBaseHeight`（默认 200），不迁移无关的 `panelMaxHeight`。自定义上限不是固定留白高度，内容少仍收紧，超限滚动。
3. 固定布局编辑工具栏与操作提示。单击选中、直接拖标题移动、拖右下角缩放，不引入双击或长按。窄窗口说明实际重排/竖向缩放规则。
4. 显示选中组件、易懂宽度/高度名称、明显拖动与缩放把手、隐藏组件的恢复入口及未保存状态。首末项禁用无效前后移动。
5. 无修改时“完成”不写布局，避免把默认内容自适应误固化为已保存网格。实际修改继续检查快照冲突；保存才落盘，取消不改用户布局。

## 保留

已保存的网格、组件开关、横向封面、最近任务位置、笔记/托盘/任务数据、纯黑/浅色/玻璃、双向切换及刚完成的轻微按钮悬停保留。网页标题阶段的未提交变更独立保留，快捷键保持未设置。

## 验证

核心回归覆盖测量先到/状态回调后到、反向顺序、宽度与详情快速往返、旧设置兼容、手动上限、无修改完成不写入、草稿改回/取消/冲突。原生隔离宿主检查固定工具栏、卡片选中/把手/隐藏找回、320/600/800pt、中英文深浅和媒体自然高度。相关测试后运行完整回归和 Release 构建，分开记录离屏、原生事件及安装版验收。

实现阶段保持当前应用及用户配置；后续用户已授权提交并发布，本机安装另行执行。
