- XNook TypeScript：72 项通过，类型检查通过。
- XNook Rust：74 项通过。网络与文件故障在受控环境注入，不是线上服务可用性保证。
- 共享联动：1 项单元与 16 项独立进程测试通过，包括冷启动偏好、超时回滚、租约/写入/隐藏失败、托盘显式显示取消迟到启动。
- 浏览器：31 项通过；包含隔离预览和模拟原生命令边界。未调用真实 Windows 剪贴板、播放器、注册表或桌面 API。
- 动效：真实 Chrome、非减少动态模式，180/300/600px 窗口、三档强度、左右边缘共采样 291 帧未越界；另将三种尺寸的动画边界写入持久回归。
- 视觉复核：浅色总览/设置、深色媒体、收起歌词和窄文件架截图，均来自受控浏览器。见 [截图目录](evidence/parity-0.2.0/)。
- 原生独立复核覆盖拖放、剪贴板、GIF、副本/恢复顺序、登录项保护、虚拟桌面版本门禁与资源许可，未发现新的交付阻断。

日志保留在 `.build/windows-parity-evidence-2026-10-17/`；主要日志与校验 JSON 另存于 [证据目录](evidence/parity-0.2.0/)。

## 安装器与交付包

配套使用 XNook 0.2.0 和并行任务已完成复核的 XIsland 0.1.6；不退回之前拟定的 0.1.5。两应用各启动一次登记路径后，支持相互唤起、共享手势及启动显示偏好。

- 测试包：`.build/XNook-0.2.0-XIsland-0.1.6-Windows-test-kit.zip`，30,274,597 字节（约 28.9 MiB）。
- ZIP SHA-256：`f5b41a83714268c8b1914c1f2f1933f44ceb0583936273c38d6b48e05809b84a`。
- XNook 安装器 SHA-256：`c57e63e09ad6b749f0760d47ec3161416734e980b729128b9c428cb430c07b0e`。
- XIsland 安装器 SHA-256：`d376e91647fe35fa9b5e2630d58c22e60087131db50e38cd94a3f350e6b84238`。

XNook 完成 Windows x64 MSVC release 与 NSIS 交叉构建。两个安装器均在本轮使用 7-Zip 独立解包：PE 为 AMD64/Windows GUI，主程序与 release 文件仅相差 Tauri 的三字节 `UNK → NSS` 包类型标记，19 个资源逐字节一致；XIsland 内置 Node 与记录的官方校验值一致。XNook 88 项、XIsland 144 项构建输入的哈希均与当前文件一致，双方联动源码相同。

压缩包生成后再次独立核对 CRC、清单完整性、每项字节数和 SHA-256，并核对包内双方构建输入。具体见 [安装器核验](evidence/parity-0.2.0/installer-verification.json) 和 [测试包核验](evidence/parity-0.2.0/test-kit-verification.json)。这些检查不执行 Windows 程序。

## 修复的交互问题

- 原果冻向外缩放叠加磁吸，在 300px 窗口中可扩到 328px；180px 窗口还受旧页面最小宽度 280px 影响。改为向内形变并按实际边距限制磁吸，不改尺寸偏好含义。
- 冷启动唤起对方时，用户从托盘要求显示当前应用，必须先持久化取消启动请求；迟到的目标不能重新夺走显示权。现已加入独立进程回归。
- 歌词时长键不再取整，防止 187.6/188.4 秒两种候选共用错误匹配结果；失败请求不写成“无歌词”缓存。

## 保留的差异与待验事项

- 用户明确选择本地 ICS；不接入未配置的 Microsoft/Google 账号，也不声称等同 macOS EventKit 账户日历同步。VTODO 未支持。
- 提醒是声音，不是系统通知横幅；不会唤醒休眠电脑，不保证休眠期间补发。
- 虚拟桌面驻留要求 Windows 11 24H2 build 26100.2605 或更新。不支持的系统返回错误并回滚开关；普通媒体功能目标仍为 Windows 10 1809+。
- 更新检查只选同仓库 Windows x64 安装资产；仅有 Mac 发布时不会误报。仅打开发布页，不自动安装。
- 未签名、未发布，Windows 安装/升级、中文输入法、多屏/DPI、全屏、真实音乐与双向切换仍需按 [验收清单](windows-test-checklist.md) 在 Windows 完成。
- 本轮团队只改 Windows 子项目及相应文档，保留 Mac 工作区的并行改动。没有自动提交 Git。
