# Windows 0.2.0 功能对齐实施

日期：2026-10-17。用户明确要求自主补齐上一轮差距，并继续实现和验证；已批准沿用独立 Windows 客户端路线。原有 Mac 工作区与 0.1.x 包保留，未经授权不提交或发布。

## 批次与所有权

1. 前端：主题/中英语言、面板尺寸与工具/历史配置、GIF/果冻/磁吸/光标、悬停/离开/空闲/纵向手势、收起歌词跑马灯、设置及恢复入口。
2. 原生系统：真实文件拖出/剪贴板、播放器激活、GIF 管理、坏数据备份恢复、开机启动、窗口主题和虚拟桌面能力、所有新命令接线。
3. 服务：歌词磁盘缓存与检索回退、失败重试、ICS 自动刷新与提醒/勿扰调度、版本检查。
4. 联动：共享手势开关/灵敏度/启动显示偏好，两客户端一致；保留事务与会话身份保护。
5. 集成：先单元与跨进程检查，再真实浏览器交互、独立审查、Windows x64 构建、安装器独立解包和源码哈希；最后交付新测试包。

## 范围决定

- 日历保留已选的本地 ICS 数据源，补自动刷新、打开来源文件/默认日历入口和提醒音。不臆造未配置的 Microsoft/Google 账号同步。
- 版本检查只选择本项目的 Windows x64 安装资产并打开发布页，不自动下载执行。尚无 Windows 发布资产时明确说明。
- 虚拟桌面能力按真实 Windows API/库能力实现，失败显式反馈，不把多显示器当作跨虚拟桌面。
- 自启动、声音、隐藏光标、恢复/删除和打开外部程序均通过用户界面动作控制；测试在隔离目录和模拟边界进行，不修改本机全局配置。
- Windows 真机结果仍是独立验收层，代码/测试/交叉编译不能替代它。

## 默认值与兼容

仍保留存储 version=1；新增 settings 字段可缺省，读取旧文件时只在内存补默认值，正常保存时写入。不覆盖损坏原件。默认主题 dark、语言 auto；提醒默认关闭、自启动默认关闭；悬停展开默认关闭、纵向展开开启。新设置范围与原生校验同步记录在 windows/PARITY-CONTRACT.md。
