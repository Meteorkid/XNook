# 布局方案与媒体氛围

用户确认：提供好用的内置布局和“自定义布局 1、2…”；媒体提供关闭、封面柔光、动态模糊三档，默认封面柔光。沿用已选横向封面、黑/浅色/玻璃背景与纯缩放按钮。

## 范围与基线

- 在 `dffbf6c` 上定向整合本机已验证连续双页预览的 20 项输入，再实现本轮功能。
- 来源当前两个文件已进入另一聊天的提醒开发。只提取与旧候选 SHA256 完全匹配的版本，来源工作区不修改；不包含尚在开发的任务提醒。
- 本轮实现、测试和构建候选；不自动提交、发布或替换本机应用。

## 布局体验

1. 内置标准三组件、专注任务、轻量媒体，缩略图展示组件位置和面积。专注任务使用等宽两列，在中等宽度仍能并排。
2. 设置的“布局方案”直接选择应用；编辑工具栏的同名入口将选择载入草稿，由原保存按钮生效。
3. 另存当前排列自动使用空闲序号命名。支持重命名、更新和删除；覆盖与删除有明确确认。
4. 切换草稿前确认未保存修改；保存/读取失败显示原因，保留输入和原布局。
5. 方案保存组件显示、顺序、位置、尺寸及内容高度适配标记；主题和用户内容保持独立。内置方案按内容收拢高度；手动调整组件尺寸后尊重固定高度。
6. 自动宽度按原主组件数量与同排全部模块数的较大值估算，包含任务模块；避免任务＋笔记被误当成单组件收窄。显式组件覆盖与手动面板宽度保持原行为。

## 数据边界

- 使用独立版本化方案库，读取不改写旧 `panelLayout.v1`。
- 配置新增可选 `fitsContent`，缺失字段与旧签名语义不变；显式为 true 的新方案才启用已保存布局的内容高度适配。拖动、排序与显隐保留标记，调整尺寸关闭标记。
- 拒绝无效布局、重复标识、无效名称、超限数据和未来版本；不覆写损坏数据。
- 写前重载方案库以保留其他窗口新增；应用时校验打开选择器时的活动布局签名，防止过期预览覆盖新修改。
- 载入布局不重建或清除笔记、文件和任务数据。

## 媒体效果

- 复用已有后台封面取色，只在媒体卡片绘制低强度颜色。
- 静态柔光不持续刷新；动态模糊约 20 秒循环、最多 15 FPS，恒定透明度，只移动背景色块。
- 动态只在媒体可见、播放中且未启用减少动态时调度。隐藏卡片、收起、快照宿主和布局编辑保持静态。
- 背景不参与命中与无障碍，不改变组件测量或按钮绘制；浅色降低色块强度。
- 系统或应用减少动态时冻结位置；暂停后恢复播放延续位置。

- 模板有效性、方案 CRUD、编号、持久化、损坏/未来版本和跨窗口冲突。

- 三档氛围、播放/隐藏/减少动态门控、时间边界、浅深色渲染与固定布局。
- 编辑工具栏及设置搜索新增入口，窄宽面板与长名称不裁切。
