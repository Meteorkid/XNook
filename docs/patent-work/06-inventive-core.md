## 三、收敛：三个核，一个闭环

### 3.1 为什么不能靠「加特征」

审查员驳组合发明的原话会是：「各区别特征均为本领域常规技术手段，其效果为各自效果的简单加和，未产生预料不到的技术效果。」只要权 1 是**并列关系**（F1 且 F2 且 F3 且 F4），这句话永远成立——因为并列结构天然允许逐项评价。

唯一出路：把并列改成**互相约束的闭环**，让「逐项评价」在逻辑上不成立——评价任何一项都必须假设其他项存在。

### 3.2 四环闭环（本案真正的创新点）

设：D 为首帧时限，k 为链长，S(I) 为区间 I 的充分性证书，R 为已读边界。

1. **D 固定 ⇒ k 必须反解**。N 个来源全跑完的耗时随 N 增长；要让 D 与 N 无关，k 只能是 D 的函数：k\*(D) = max{k : Σ_{i≤k} ĉᵢ ≤ L_eff}。**这一步把「可预取性」从判据降级为预测器**——P 不再直接决定剪不剪，而是用来估计 ĉ，再由 ĉ 反解 k\*。
2. **k 变化 ⇒ S 必须重算**。被移出链的来源原本覆盖的区间失去证据，S(I) 由「成立」变「不成立」，必须重新进入待补集合。否则系统会凭一张过期证书判定「已充分」而漏字幕。
3. **S 重算 ⇒ 只能作用于未读区间**。重算会产生新的候选；若允许回写已读区间，就变成回溯改已呈现条目（这恰是 S01/A02 主张的「保护已读前缀」，也恰是本方案明文禁止的）。
4. **R 反过来约束 D 的有效域**。已读区间不再需要 D 保护，其时限预算可让给未读区间——这使 A3/A4 成为闭环的自然推论，而不是外挂的优化。

**四环闭合后，任一环缺失即整体失效：**

| 缺失 | 后果 | 可测指标 |
| --- | --- | --- |
| 无 1（无反解） | 首帧延迟随 N 增长，D 退化为愿望 | P95 延迟 vs N 的斜率 > 0 |
| 无 2（证书不重算） | 剪枝后漏字幕，或为保险起见全量重跑 | 漏字率上升 / 重复转写次数上升 |
| 无 3（可回写已读） | 已呈现文本跳动，渲染重排次数暴涨 | 重排次数、条目变更率 |
| 无 4（R 不反馈） | 修复窗口无限增长，缓冲与候选集合无界 | 峰值 RSS 随播放时长增长 |

**关键论点**：现有技术最多覆盖其中两环。S01/A02 有 3、4 的雏形（保护已读前缀）但没有 1、2；CN121691833A 有统一时间基与迟到截断（接近 2），但没有 1 的反解与 4 的预算回流；US10021445 有 seek 复用（接近 3 的复用面），但没有证书概念。**没有一篇把 1-2-3-4 锁成闭环。**这就是意见陈述的主线，也是权 1 修改的方向。

### 3.3 三个核的定位

| 核 | 在闭环中的位置 | 单独被驳的风险 | 组合后的作用 |
| --- | --- | --- | --- |
| A1 链长反解 | 环 1 | 中（像资源约束调度） | 让 D 成为约束而非参数 |
| A2 可达性注销 | 环 1 的边界条件 | 低（先验判定 vs 事后超时） | 消灭「等待—超时」路径，内存结构性下降 |
| B1 充分性证书 | 环 2 | 中（像缓存命中） | 把「有没有」换成「够不够」，且证书可被降级 |
| C1 三时钟偏斜 | 环 4 的前置 | 中（像时间同步） | 保证长时播放不漂移，使 R 的边界可信 |

C1 单独看最弱，但没有它，环 4 的「已读边界」在 2 小时播放后会偏移 100–200 ms，边界本身不可信——这是它与整体的因果绑定，也是它值得写进从权的理由。

## 四、防御性权项阶梯（答复时逐级退守，全部先写进说明书）

原则：**层级只做加法，不做替换**。层 n 是层 n−1 的进一步限定，因此任何时候上提都不超范围（A33），且不必重写前序部分。以下措辞为可直接插入权 1 的候选文本，均须先补入说明书对应段落。

### 层 0 · 现权 1（2026-11-15 已重写，内含原层 1 与原层 3）

> 六字段契约 + **修正耗时 ĉ 与有效预算 L_eff 反解链长 k** + **区间充分性证书（覆盖率＋等级＋「k 内工作已终结」前提）** + **k↔证书闭环重判（限 N_iter 次）** + D 到点渲染 + 晚到只写未读 + 稳定边界。**这就是提交文本**，答复时从这一版起算。

层 0 的写法已不再是「P 两支剪枝」。原因见 3.1：P 两支剪枝是并列结构，与 D 到点渲染之间没有因果关系，审查员只要说「剪枝属常规、到点不等属必然」，就能把两句都驳掉。重写后 P 只剩一个用途——估计 ĉ；k 由 L_eff 反解；证书的判据与效力又反过来决定反解时计入谁。三者的参数互为输入，逐项评价在逻辑上不再成立。

> **2026-11-14 权项比对结论**：对三件高威胁件（`EP4264602B1`、`US12254869B2`、`US9305552B2`）的授权文本权项逐项比对后，**层 0 已足够**——三件均缺 L3（六字段契约）、L5（P 剪枝）、L6（首帧时限）、L8（状态机与延迟上界）四组核心限定，且 EP 与 US12254869 在 L7（是否回改已呈现）上与本申请**方向相反**。故答复一通时**不必**为求稳即上提层 1；层的启用应留给「审查员确实以某篇评到具体限定」时。详见 `01-prior-art.md` §5.4。

### 层 1 · 链长反解（环 1）—— **已并入层 0**

> ~~原文保留备查~~：按各所述证据提供者的估计耗时确定链长上界 k，使排序在前 k 位的证据提供者的估计耗时之和不大于有效预算 L_eff……

### 层 2 · 可达性注销（环 1 边界）

> 对估计耗时超过所述 L_eff 且所述可预取性要求为必需可预取的证据提供者，在所述首帧时限 D 到达之前注销其向所述候选条目集合写入的权限，并把其产出时间区间标记为不可达区间；所述不可达区间不参与区间充分性判定，且不为所述不可达区间保留音频缓冲。

要点：与「超时降级」的区别必须写死在文字里——**在 D 到达之前**、**注销写权限**（不是等它超时后再丢弃）、**不为它保留缓冲**（内存是结构性下降，不是策略性放弃）。

### 层 3 · 充分性证书 + 短路（环 2）—— **已并入层 0**

> ~~原文保留备查~~：为每一所述时间区间单元维护充分性证书，所述证书在其时间覆盖率不小于覆盖率阈值、且覆盖该区间的候选字幕条目中的最高证据等级不低于等级阈值时成立……

并入后的正式措辞见权 1 第 5 段（证书判据三条件）与第 6 段（k↔证书闭环重判、限 N_iter 次、只及未读区间）。比原层 3 多了一条关键限定：**证书的成立以「k 内证据提供者均已执行完毕或已确定为不执行」为前提** —— 这一条把证书从「缓存命中」的类比里拽出来，因为缓存命中不要求「生产已完成」。

要点：三句话锁定三件事——证书的**判据**（覆盖度×等级，不是「有无缓存」）、证书的**效力**（短路执行，省的是推理调用）、证书的**失效与作用域**（随 k 变化重判、只写未读）。这是唯一同时咬住环 2 与环 3 的层。

### 层 4 · 三时钟偏斜（环 4 前置）

> 估计所述音源自身的媒体时间轴、所述音频捕获接口的采样时钟与所述推理单元的输出时钟三者之间的偏斜量，把所述偏斜量作为所述绝对源时间戳索引的状态分量；所述音频指纹重锚的匹配容差按所述偏斜量修正，所述已读状态的判定按修正后的绝对源时间戳进行。

要点：不讲「提高同步精度」，只讲「索引状态分量」与「容差修正」——把时间同步问题落到数据结构上，避开「常规时间同步」的类比。

### 装置权 8 的同步要求（易被忽略的 26.4 陷阱）

层 1 与层 3 已于 2026-11-15 随方法权一起并入：权 8 的链剪枝模块已限定为「按修正耗时与有效预算 L_eff 反解链长」，并已在该模块内增设**证书维护单元**（作为链剪枝模块的子单元，不新增第七个模块，图 8 与附图标记 1–6 不变）。余下各层的同步要求：层 2→链剪枝模块增加「可达性注销」子功能；层 4→「绝对源时间戳索引与重锚模块」增加偏斜分量。**若只改方法权不改装置权（权 8），装置权会因缺少对应结构而被指 26.4 得不到支持。**答复时须成套改。

## 五、实验设计：把「断言」换成「一条斜率」

审查员唯一会认真看的效果，是**一条斜率为 0 的曲线**。本案要证的不是「延迟低」，而是「延迟对 N 不敏感」。下面是可直接照做的五组，全部在本机（Apple M3 Max / 36 GB）可跑，不需要外部数据集——素材用公开视频 + 系统回环即可。

| 组 | 变量 | 记录指标 | 要证的命题 |
| --- | --- | --- | --- |
| G1 可预取点播 | N ∈ {1,2,3,5}，同一视频 | 首帧延迟 P50/P95、重复转写秒数、峰值 RSS、推理调用次数 | P95 对 N 的斜率 ≈ 0；重复转写次数随 N 增长而**不增** |
| G2 不可预取直播 | N ∈ {1,2,3,5}，同一会议流 | 同上 + 音频缓冲字节数、链路重建次数 | P95 斜率 ≈ 0 且缓冲字节数与 N 无关（层 2 的直接证据） |
| G3 跳变 / seek | 20 次随机 seek | 重锚命中率、补处理区间数、seek 后首帧延迟 | 补处理区间数 ∝ 未覆盖区间数，而非全量重跑 |
| G4 长时播放 | 连续 2 h | 字幕相对音频的偏移量随时间 | G4 是层 4 的唯一证据：无偏斜标定时偏移单调增长，有标定时收敛 |
| G5 阈值抖动 | 人为注入 P ±0.05 抖动 | 链路重建次数、缓存命中率 | 双阈值滞回把重建次数压到单阈值方案的 1/3 以下（方向性断言，须实测填数） |

**基线设置（必须有，否则曲线无意义）**：
- B1 = 不剪枝、等全部来源返回（现有技术的典型做法）；
- B2 = 只做超时降级、不做链长反解；
- B3 = 本方案层 0；B4 = 层 3（含证书短路）。

**填写纪律**：测得前，一律写「机理推导，未实测」；测得后，把命令、输入素材哈希、原始 CSV 一并留档。**任何未跑出的数字不得写进说明书。**

## 六、防规避与防无效（defensive 的另一半）

创造性只是第一关，第二关是「授权后别人换个词就能绕开」。防御性撰写要同时做三件事：

### 6.1 同义定义表（防「改词规避」）

在说明书术语表增补同义栏，明确以下各组在本申请中为同一技术特征的不同表述：

| 本案用词 | 应写入的同义表述 |
| --- | --- |
| 可预取度 P | 后续数据可得性度量、可前瞻读取程度、lookahead availability |
| 证据等级 | 来源可信序、证据优先级、来源可靠度排序 |
| 充分性证书 | 区间覆盖判据、证据充分度标记 |
| 链长上界 k | 可执行来源数上限、有效链长度 |
| 可达性注销 | 不可达来源剔除、写权限注销 |

### 6.2 负面限定（防「等同替换」与「事后诸葛亮」）
