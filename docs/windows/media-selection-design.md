# 网易云音乐、QQ 音乐与播放器选择

日期：2026-10-17。用户授权优先适配网易云音乐和 QQ 音乐，并加入手动选择播放器。

## 行为

- 音乐页始终提供播放器选择框，包含“自动选择”和系统当前公开的各播放器。
- 自动模式优先正在播放的网易云音乐/QQ 音乐；两者同时播放时优先系统当前会话，其次保留当前已选播放器，最后稳定排序。没有这两款正在播放时跟随系统当前来源。
- 手动模式按实际 SourceAppUserModelId 固定来源，重启保留。来源退出时明确显示离线，不控制其他播放器。
- 控制命令携带界面显示时的 sourceId 和 sessionToken；枚举或选择改变不能让暂停/上下首/跳转误发给别的软件或同 ID 的另一个会话。令牌在同一会话对象内稳定，换对象时重新生成。
- 来源切换立即清空旧曲目/歌词并禁用旧控制；旧快照和旧歌词异步结果不得覆盖新选择。
- 对缺失媒体会话的客户端明确说明检测条件，不以名称匹配或全局媒体按键冒充适配。

## 技术边界

继续使用 Windows GSMTC，枚举 GetSessions。应用识别以有依据的精确 ID、可执行文件名或包家族为准，不用泛化 substring。每个播放器分组使用原始 sourceId，若同一应用公开多个会话则选择其正在播放/系统当前会话；首版不提供浏览器标签级选择。

设置 v1 增加可选 `preferredMediaSourceId: string | null`；旧文件缺少该字段视为自动选择，新写入保留字段，读坏文件保护不变。

## 验证

纯规则测试覆盖两款目标播放器、混合播放、固定离线、来源冲突/误识别、旧设置迁移和过期请求。浏览器通过真实选择框验证选择、持久化、离线、恢复和控制来源。Windows MSVC 构建后生成 0.1.1 测试包，保留旧包。客户端来源标识的取证、受控回归与 Windows 真机结果分开记录。
