# X Nook v1.3.26 — 布局、媒体氛围与软件授权

日期：2026-10-27

本版将软件授权与最新布局方案、媒体氛围、连续双岛联动整合，升级保留已有笔记、任务、文件托盘、布局与外观偏好。

## 试用与授权

在 **设置 → 授权** 联网开始 14 天完整功能试用，或输入从官网购买、管理员发放的邀请码，激活月度、年度或永久使用权。

- 每份付费授权最多绑定 **3 台设备**，可在授权页解绑本机后换机。
- 首次试用、激活、刷新和解绑需要联网，验证后可离线使用最长 **7 天**，且不能超过试用或月度、年度授权的期限。
- 永久使用权无需续费，但仍需至少每 7 天联网核验一次。
- 旧版 `XNK1` 离线邀请码需联系管理员迁移。

到期后停止主面板、媒体轮询、日历与任务提醒、Claude 通知监听、双岛预览和全局快捷键，保留激活、购买和本地资料导出；重新验证后恢复原配置。尚未保存的笔记继续保留在内存中，导出包含最新编辑内容。常驻与休眠唤醒都会检查期限，校准误设的系统时间后可通过联网验证恢复。

购买入口：[XNook 官网](https://www.imagentx.top/zh/products/xnook)。设备识别使用硬件标识的 SHA-256 哈希，原始硬件标识不发送到服务器，授权凭据存放于本机钥匙串。

## 布局方案

- 保留了标准三组件、专注任务、轻量媒体三套内置方案，以及自定义方案的另存、重命名、更新和删除。
- 保留了方案缩略图、未保存草稿切换确认和其他窗口同期修改检查。
- 保留了内置方案按内容收拢高度、任务与笔记并排时的自动宽度计算，以及用户手动设置的组件尺寸。

在设置中搜索 **布局方案** 可管理方案；从 **编辑布局 → 布局方案** 选择时，方案先载入草稿，保存后才生效。

## 媒体氛围与双岛联动

- 保留了 **关闭、封面柔光、动态模糊** 三档媒体背景，默认使用封面柔光，效果限制在媒体卡片内部。
- 动态背景在暂停、隐藏或减少动态时停止流动，重新播放后延续原位置，不改变媒体控制和歌词布局。
- 保留了双指连续双页预览、短滑回弹、提醒优先让位、快速反向与迟到请求保护。
- 保留了已确认的面板高度行为，以及设置、关闭和媒体主按钮的纯缩放反馈。

## 验证与安装包

本版重新执行了整合后的完整源码回归；具体测试数量、跳过项、正式公钥匹配、签名、DMG 只读挂载与源码哈希记录见 [发行验证](https://github.com/Meteorkid/XNook/blob/v1.3.26/docs/releases/verification-1.3.26.json)。源码和包校验不代替真实购买、物理触控板手势与用户设备授权验收。

安装包面向 Apple Silicon **arm64**，最低 macOS **14**，沿用 **ad-hoc 签名与 Hardened Runtime**；未使用 Developer ID 或 Apple 公证。本次不包含 Windows 版变更。
