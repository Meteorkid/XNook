# X Nook v1.3.25 — 试用与软件授权

日期：2026-10-27

本版新增软件授权：首次联网可开始 14 天完整功能试用，也可通过官网购买或管理员发放的邀请码激活月度、年度或永久使用权。原有笔记、任务、文件托盘、布局及双岛切换配置继续保留。

## 开始使用

在 **设置 → 授权** 查看当前状态、试用剩余时间、使用权有效期及离线使用期限；点击“联网验证 / 开始试用”或粘贴邀请码后激活。

- 每份付费授权最多绑定 **3 台设备**，可在授权页解绑本机后换到另一台设备。
- 首次试用、激活、刷新和解绑需要联网，成功验证后可离线使用最长 **7 天**，且不能超过试用或月度、年度授权的到期时间。
- 永久使用权无需续费，但仍需至少每 7 天联网核验一次。
- 旧版 `XNK1` 离线邀请码不能直接用于新版，请联系管理员迁移。

购买入口：[XNook 官网](https://www.imagentx.top/zh/products/xnook)。

## 到期与数据保护

- 到期时停止主面板、媒体轮询、日历提醒、任务截止监控、Claude 通知监听、双岛预览和全局快捷键，保留授权、购买及数据导出入口。
- 常驻运行与休眠唤醒都会重新检查有效期，联网恢复或激活后重新启用服务与原配置。
- 保留了尚未成功写入磁盘的笔记，导出时包含最新内存内容，恢复使用后继续使用原笔记实例。
- 已过期的本地凭据不会因回拨时钟而恢复；系统时间曾误设到未来时，校准时间并联网验证即可重新建立有效状态。

设备识别使用硬件标识的 SHA-256 哈希，原始硬件标识不发送到服务器；授权凭据与设备令牌保存于本机钥匙串。
