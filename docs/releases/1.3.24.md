# X Nook v1.3.24 — 连续双页切换与提醒联动

日期：2026-10-27

本版集中改善 X Nook 与 X Island 的切换体验：加入双指拖动中的连续双页预览，处理两款岛尺寸不同造成的衔接问题，并配合 X Island 的任务提醒优先显示机制。建议与 **X Island 2.0.12** 一起更新。

## 新增

- 新增了连续双页预览，在收起的岛上左右双指滑动时，可以逐渐露出另一款岛的内容。
- 新增了松手确认与短滑回弹，拖动未达到阈值时返回当前岛，达到阈值后再完成切换。
- 新增了提醒优先显示的协作保护，X Island 发出任务完成、审批或提问提醒后，过时的切换请求不再把旧岛重新显示出来。

## 切换与动画修复

- 调整了切换时两页的共享边界与宽高过渡，使不同尺寸的岛能够连续衔接。
- 修复了交接过程中先恢复旧岛内容、后隐藏窗口的顺序问题，避免松手后旧岛再次闪回。
- 调整了果冻动画的插值与内容承载方式，避免背景和内容重复启动尺寸动画。
- 改善了快速反向、回弹途中再次拖动、准备超时和迟到回复的处理，保留当前窗口直到目标可以接管。
- 保留了对端未运行、版本不支持或暂未准备好时的安全切换，此时松手后启动或显示对端，不显示虚构的预览。
- 保留了应用与系统的减少动态设置，切换不会替用户改写这些偏好。

## 按钮与现有界面

- 将设置、关闭和媒体主按钮的悬停反馈统一为了轻微缩放，去掉了上浮等位移反馈。
- 保留了 1.3.23 的自动内容高度、自定义高度上限、网格拖动缩放和纯黑、浅色、玻璃等已有背景设置。
- 保留了笔记、文件托盘、NookFlow、媒体详情和已保存布局，无需重置偏好或清空内容。

## 使用与兼容

在 **设置 → 联动** 开启双指横滑切换后，从收起的岛开始左右滑动。连续预览要求两款应用已经运行、版本支持、位于兼容的显示环境，并且对端处于可预览的收起状态；否则继续使用安全的普通切换。

任务提醒开关位于 **X Island 2.0.12** 的展开面板铃铛和常规设置中，X Nook 负责正确让位及拒绝过时切换，不替用户批准权限或回答问题。

本版没有纳入仍在独立工作区开发的布局方案库、媒体氛围或软件授权模块；XNook 的自动收起设置继续沿用原有规则，XIsland 的统一零延迟收起由其 2.0.12 版本提供。
