# Windows 0.3.1 最终功能对齐记录

日期：2026-10-17。本轮从0.2.0继续对照当前Mac实际界面，先完成 [0.3.0工作流补齐](parity-verification-0.3.0.md)，再处理极窄尺寸和歌词时长微漂移。0.3.0包作为中间冻结结果保留，0.3.1为本轮最终交付。

## 实现结果

- 概览直接操作任务、所选播放器、笔记和文件；全部历史分页与详情，显示起止和关联资料；笔记快照恢复幂等。
- 所选日日历概览、完整日详情、进行中/结束状态与来源色；跨日、午夜排他、月网格边缘日期及刷新焦点保护。
- 同曲网络失败后持续退避恢复、真实倍速插值、播放波形；小于1秒的时长微漂移可复用已匹配歌词，但来源/曲名/艺人/专辑和精确8秒边界仍校验，不延长缓存寿命。
- 文件逐项可用状态和大小、坏项重试、慢刷新续跑；保留原文件引用与历史快照。
- 收起横拖/下拖、展开横滚保护、右键设置/安全退出、托盘设置/更新排队；重复快捷键不会多次新建。
- 动态高度与紧凑布局。下限对齐Mac：普通药丸40×8、歌词药丸60×10、面板160×160；160px使用下拉导航和纵向控件，极矮药丸保留点击区。极窄药丸右键时临时扩宽宿主窗口，关闭后恢复原尺寸。保留旧Windows默认值和上限，旧Store v1兼容。

保留网易云音乐/QQ音乐优先、手选播放器、本地ICS和XIsland双向切换。不会用模拟媒体或日历替代真实来源。

## 仍需 Windows 实机确认

代码层已处理本轮审计确认的可迁移功能差距；这不等于两平台真实体验已经完全一致。Windows安装/升级、网易云与QQ精确版本的SMTC能力、文件拖放/剪贴板、极窄点击区/菜单、托盘焦点、双向切换、多屏/DPI/IME仍按 [验收清单](windows-test-checklist.md) 实测。

本地ICS是用户确定的数据源选择，账户日历同步不在本轮范围；VTODO不导入。提醒是声音、不唤醒休眠电脑。虚拟桌面驻留仍要求Win11 24H2 build26100.2605+。未签名、未发布、未自动提交Git。视觉按Windows实现适配，没有宣称与Mac逐像素一致。
