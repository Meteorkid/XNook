# X Nook v1.3.31

发布日期：2026-11-17

本版重写媒体接入链路，从只支持 Apple Music / Spotify 扩展到系统级 Now Playing，并新增来源锁定。同时纳入开发分支中已完成的实时字幕与授权管理功能。

## 媒体接入

- 媒体信息改以系统 MediaRemote 为主来源：读取标题、艺人、专辑、封面与进度，用播放进程 PID 反查真实来源应用。QQ 音乐、网易云音乐、哔哩哔哩等客户端以及浏览器网页音视频均可识别。
- Apple Music / Spotify 保留 AppleScript 增强：提供更精确的播放位置与原始封面；脚本失败或来源不匹配时不影响已有的系统快照。
- 新增「媒体来源」设置：默认自动跟随系统，可锁定 Apple Music、Spotify、QQ 音乐、网易云音乐、哔哩哔哩或任意 Bundle ID。锁定时只显示并控制指定应用，其他播放器不会串入；无脚本接口的应用未成为系统播放源时，岛上显示「等待 ×× 播放」并禁用控制按钮。
- 修复快照竞态：元数据与来源 PID 串行读取并前后校验，播放器切换瞬间不再出现标题与来源错配；不一致时保留上一帧内容。
- 展开面板标出当前来源应用，封面悬停提示显示应用名称。

## 实时字幕

- 捕获系统正在播放的声音，在灵动岛下方显示本机语音识别转写文字。需「屏幕录制」与「语音识别」授权，识别在本机完成。
- 实现证据优先级链调度：绝对源时间轴、识别会话切换的迟到回调过滤、播放器跳变检测与逻辑时钟回退。
- 设置页增加授权状态诊断与跳转入口；遵循「减少动态效果」设置。

## 授权管理

- 新增许可证激活入口、到期提醒窗口与授权状态展示，授权核心逻辑独立为可测试模块。

## 验证与安装包

- 安装包：`XNook-1.3.31.dmg`，Apple Silicon（arm64），macOS 14 或更高版本。
- 延续 ad-hoc 本地签名，签名完整性已验证；尚未使用 Developer ID 签名或 Apple 公证。
- 发布前全量测试：**526 项通过，0 失败，14 项条件跳过**（其中 XNook 488 项、授权核心 38 项）。
- QQ 音乐 / 哔哩哔哩是否发布系统 Now Playing 信息的实机验证：本机已将两应用打开并完成 MediaRemote 接口探测，接口链路可用；是否发布播放信息的最终结论需用户手动播放后读取快照确认，见下方说明。

## 已知限制

- 系统 MediaRemote 只能读取当前 Now Playing，无法主动查询后台应用。锁定无脚本接口的应用时，必须先让它成为系统正在播放的来源。
- 视频自带字幕文件（.srt / .ass / CC 字幕）尚不支持；实时字幕是语音识别转写，不是视频原文。
- ad-hoc 签名版本首次打开需要右键「打开」绕过 Gatekeeper。
