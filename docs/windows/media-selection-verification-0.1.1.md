# XNook Windows 0.1.1：播放器优先适配与手动选择

日期：2026-10-17。已生成 Windows x64 未签名预览安装包；**网易云音乐、QQ 音乐最新版的 Windows 实机验证仍未完成**。

## 已实现

- 精确识别网易云音乐与 QQ 音乐的已知 exe 来源，绝对 Windows 路径取完整基名，保留原始 sourceId；未知来源仍能手动选择。
- 自动模式优先正在播放的两款目标播放器；两者均播放时先系统当前，再保持已有来源，最后稳定排序。
- 音乐页手动固定播放器，选择持久化；固定来源退出时显示离线，不转控其他应用，恢复后继续读取。
- 下拉列表与曲目区域分别更新，轮询不重建正在操作的选择框或进度条。
- 按钮/进度条携带显示时的来源 ID 和会话令牌。原生核对绑定与会话存活，拒绝旧会话操作，避免同名来源重建时误控。
- 原有 v1 数据文件缺少新设置字段时按自动模式读取，不重置笔记、任务或日历。
- 歌词采用完整艺人名匹配，保留斜杠和 Live/Remix 信息；无法确认的候选不冒认。
- XIsland 联动保持不变，配套版本仍为 0.1.4。

## 版本与证据边界

用户要求两家最新版。QQ 官方下载页本次显示 22.7.6（2026-10-13）；网易官方下载入口确认，但版本号未可靠取得。精确来源标识来自可核对的媒体消费者发布源码，不是厂商对全部版本的保证；未下载到厂商安装包，也没有在 Windows 上运行两款播放器。

详情与来源见 [兼容性核查](music-compatibility-2026-10-17.md)。如果客户端不向 Windows 公开媒体会话，选择框不会凭空出现该软件；缺少真实时间轴时不能据此宣称歌词同步完成。本次没有安装插件、注入 DLL、用窗口标题猜曲目或用全局媒体键替代定向控制。

## 真机操作

1. 安装 XNook 0.1.1，打开网易云或 QQ 音乐并播放歌曲。
2. 展开 XNook → 音乐 → 播放器，选择目标软件。
3. 对照歌名、封面与播放进度，验证暂停、上下首、拖动进度和歌词。
4. 同时打开另一个播放器，检查固定来源不被抢走；关闭并重新打开固定来源，再重启 XNook 检查记忆。
5. 若没有出现在列表或缺少某项能力，记录精确客户端版本和表现，按 `windows-test-checklist.md` 反馈；不能把“最新版”当成版本号。
