# Windows XNook 与 XIsland 验收清单

本清单用于另一台 Windows 电脑。记录 Windows 版本、两个应用版本、播放器版本、屏幕分辨率和缩放。构建成功与安装包校验均不代表此表已通过。

## 安装与联动

0.3.2重点回归：右键首次退出、保存失败后取消/重试/放弃、慢盘保存中切岛；确认两个应用的显示权与草稿均保持。

1. 安装配套 XNook 和 XIsland。首次分别运行一次，以注册各自安装路径。
2. 只开 XNook，点击切换按钮：已注册但未运行的 XIsland 应启动、显示；成功后 XNook 隐藏。
3. 从 XIsland 切回 XNook；检查连续往返和横向触控板手势。
4. 在设置/笔记编辑区域横向滚动不应误切换；文字未保存时退出不得静默丢失草稿。
5. 目标未安装、路径失效或启动失败时显示错误，源应用保持可见。
6. 两应用同时启动、快速切换、切换中退出对方；不得永久双隐藏或持续互抢。
7. 从托盘显示另一应用、重复启动应用，显示权协调与按钮切换保持一致。
8. 切换后进入/离开全屏，已让位的应用不能自行重新出现。
9. 两边分别修改手势开关、低/中/高灵敏度及启动显示偏好，另一边应读到相同值。关闭手势后按钮仍可切换。
10. 设置启动显示 XIsland/上次使用，关闭两应用后重开 XNook；延迟启动对方期间从托盘显式显示 XNook，迟到的对方不得再次夺走显示权。

## 工具工作流

- 异常输入：超过预算的ICS明确拒绝，不可满足的重复规则超时后界面仍能编辑，下一份正常日历可以导入；自动刷新语义错误和超限时保留旧日历。
- 歌词资源：异常长标签不会卡住界面，合法备用候选可继续显示；真实服务验证不得覆盖他人记录。
- 容量：大笔记反复关联任务超限时当前任务和既有历史不变；确认删除历史只删记录、不删源笔记/文件，容量释放后保存恢复。
- 并发设置：外观设置操作尚未完成时固定网易/QQ，重启后仍保留播放器选择。
- 同时提醒：多个事件同刻开始、0分钟提前量，成功播放一次后全部去重；声音失败后可重试。
- GIF恢复：旧半删条目可移除，坏元数据不堵健康项；未知文件必须保留。删除中断后重新打开设置能重试清理，原始导入文件不受影响。

- 0.3.0 概览：直接开始空标题任务、结束、操作所选播放器、新建/打开最近笔记和文件；长按 Ctrl+N 只产生一次新建，中文输入法组合期间不触发快捷键。
- 全部历史：将最近记录上限设为1，仍能通过“全部历史”访问更早记录、翻页、查看真实起止及关联资料。删除关联笔记后多次打开只能恢复同一份副本，历史快照正文保留。
- 日期与焦点：今天概览跳过已结束，过去日期保留；跨日事件逐日标记，午夜结束不标次日。月历前后溢出日期可查看。键盘聚焦第二条日程后自动刷新，Enter仍启动同一条日程。

- 播放器选择（0.1.1）：网易云音乐和 QQ 音乐均使用官网下载最新版，记录“关于”的精确版本。两者同时运行并分别播放/暂停；固定 QQ 后其他软件开始播放不能夺走控制，网易同理。关闭固定播放器应提示离线，重新打开后恢复；重启 XNook 保留手选。回到自动后再验证优先顺序。
- 检测与能力：记录实际来源 ID；未出现在下拉列表不算已适配。分别测试信息、封面、控制、进度和 seek；缺少进度时不能把歌词显示当成同步已成功。若安装过第三方 SMTC 插件，单独注明，不能混同官方原生能力。
- 媒体：真实音乐应用切歌、暂停、上一首/下一首、拖动进度、关闭播放器、休眠恢复；封面/歌名/歌词应来自同一首歌。不支持的操作应禁用。
- 歌词：有同步歌词、仅纯歌词、无歌词、网络失败；快速切歌后旧请求不能替换新歌歌词。
- 缓存与封面：重启后歌词命中磁盘缓存；断网与恢复不把网络失败缓存为无歌词。点击封面应激活界面所选播放器；播放器重启后的过期会话不得误控新来源。
- 日历：本地 ICS 含全天、跨日、时区、重复、例外与取消事件；对照原日历。修改文件后刷新；断开磁盘时保留原数据并报错。
- 日历自动行为：修改 ICS 后等待所选刷新间隔；应用隐藏时也刷新。分别测试提前 0/5/15 分钟提醒音、声音失败后重试、重启去重、跨午夜勿扰；休眠期间不保证唤醒和补发。打开来源应是所选 ICS。
- 笔记：新建、中文输入、搜索、重命名、删除撤销、导出 Markdown/TXT、重启恢复；模拟保存失败后草稿可恢复。
- 文件架：拖入文件/文件夹、打开和定位、去重；文件移走或磁盘断开应说明原因。
- 文件输出：点击复制后在资源管理器粘贴；拖出到资源管理器或支持文件接收的应用，源文件保留。取消拖动、中文路径、多文件、失效路径分别验证。
- 文件状态：一个来源磁盘断开时其他项仍显示大小；重连后刷新恢复。刷新慢时继续添加/移除文件，最终状态应对应最新文件架，历史引用不被改写。
- NookFlow：手动或从日程开始、关联笔记和文件、结束、重启看历史。清空文件架后历史引用仍可打开原文件。
- 外观与交互：深/浅/系统主题、中英文、最小和最大尺寸、工具与历史开关；用户笔记/歌曲名不翻译。导入 GIF、删除应用副本不动原件，减少动态效果停止动画；窄浮岛下果冻/磁吸不裁切，鼠标仅在配置的收起区域隐藏。
- 恢复：在隔离测试数据目录制造损坏存储，普通读取不覆盖原件；确认恢复后先生成原始字节备份再建空数据，“查看备份”可定位该文件。

## 系统与安装行为

- 收起态横拖移动窗口后不能误展开；向下拖动展开，封面/切换按钮仍可点击。展开后的横向滚动不切岛。取消拖动后的下一次点击不应丢失。
- 药丸右键设置/退出；托盘设置/检查更新在双方切换与冷启动中仍遵守显示权。写盘失败时退出菜单必须保留草稿。
- 面板短内容缩小、长内容达到设置上限后滚动；切换工具和调整宽度后无不断变高/裁切。真实倍速播放器按0.5/1/2倍验证歌词；同一首歌断网超过短重试后重连可自动恢复，关闭歌词后不继续重试。
- 0.3.1极窄尺寸：普通40×8、歌词60×10仍可点击展开；160px面板通过下拉导航访问工具，160×160设置与恢复确认可滚动/取消；极窄药丸的右键菜单应暂时扩宽窗口，关闭恢复原尺寸。
- 时长轻微波动：同曲时长变化小于1秒时歌词不闪空；来源/艺人/版本变化仍重新查询，8秒匹配边界不放松。

- 100%/150%/200% 缩放、多屏与负坐标屏幕；切屏不越界，展开后编辑不随鼠标乱跳。
- 展开编辑支持中文输入法；悬停或后台刷新不抢焦点；透明边缘不吞掉其他应用点击。
- 全屏游戏/视频、最大化窗口、系统锁屏与睡眠恢复；减少动态效果偏好。
- 安装、升级、卸载；文档/笔记不被升级覆盖；记录任务管理器的 CPU/内存。
- 开机启动：显式开关后重新登录验证；系统已禁用启动项时给出提示，不绕过系统设置。
- 虚拟桌面：支持的 Windows 11 24H2 build 26100.2605+ 测试驻留与关闭驻留；旧系统应报错并回滚开关。此能力不等于多显示器。
- 更新：只识别同仓库 Windows x64 安装包；仅有 Mac 发布时不能报 Windows 更新。检查与打开发布页均不自动安装。

记录：版本、步骤、预期、实际、截图或录屏、是否可重复。不要附带个人笔记正文、日历内容或认证信息。
