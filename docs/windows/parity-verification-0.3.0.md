# Windows 0.3.0 工作流对齐验证

日期：2026-10-17。基于本轮开始时 Mac 实际用户入口重新审计，完成下列功能和交互差距。没有改动 Mac 源码，没有提交、推送或发布。

本报告保留0.3.0冻结结果；同轮后续0.3.1已继续处理极窄尺寸和歌词时长微漂移，最新结果见 [0.3.1报告](parity-verification-0.3.1.md)。

## 本轮实现

| 领域 | 已完成的 Windows 行为 |
| --- | --- |
| 概览 | 直接开始/结束任务、操作当前播放器、新建/打开最近笔记、添加/打开常用文件 |
| 历史 | 最近记录之外可访问全部历史，每页20条，稳定按真实结束时间排序；详情显示实际起止和关联资料 |
| 笔记 | 从任务快照恢复后重绑该任务引用，重复打开不重复创建；活跃任务可继续同步编辑，旧历史正文快照独立保留 |
| 日历 | 所选日概览最多两条，今天跳过已结束、过去日期保持完整；详情标记进行中/已结束和稳定来源色；月历跨日、午夜排他及边缘日期正确显示 |
| 音乐 | 概览播放控制仍绑定sourceId/sessionToken；默认波形跟随播放与减少动态效果；暂停返回普通药丸，歌词和曲目信息独立开关 |
| 歌词恢复 | 三次短重试失败后，以15/30/60/120秒继续恢复；切曲/关闭取消；真实倍速参与位置插值，精确时长候选匹配保留 |
| 文件 | 每项独立检查文件属性和大小，断开/失效项不影响其他项；保留所有引用与历史快照，可刷新恢复；忙碌时追加的刷新会续跑 |
| 交互 | 收起药丸横拖移动、向下拖动展开、拖后点击抑制；展开横滚不切岛；重复快捷键不连续新建笔记 |
| 系统入口 | 药丸右键设置/安全退出；托盘设置/检查更新先取得显示权再通知界面，启动前动作可补领 |
| 布局 | 展开高度按自然内容收缩，以用户设置为上限；长内容仍可滚动，360px文件操作可用 |

Mac 未发现真实界面的进度百分比/超时自动结束、来源筛选/事件增删、音量或歌词点击跳转，不把仅存在于模型或未接线的方法虚构为必须迁移的功能。

## 验证结果

- TypeScript 类型检查、前端生产构建通过；100项逻辑测试通过。
- 完整桌面特性的 Rust 测试78项通过，覆盖新增文件状态、托盘队列和播放倍速。
- 浏览器43项通过，其中本轮12项覆盖概览直接操作、43条历史翻页、笔记恢复幂等、键盘重复、日历状态/焦点、文件刷新竞态、拖动、菜单/托盘、动态高度和歌词断网恢复。
- 独立只读复核复现并关闭：历史模式挡住新日程任务、月历前溢日期遗漏、刷新焦点错绑到另一条日程、文件忙碌刷新丢请求、高频拖动更新积压。服务测试另复现并修复重试定时器触发后取消的微任务竞态。
- 真实 Chromium 布局检查覆盖浅色概览、历史详情和360px文件架。动态窗口测试把原生resize合同映射到浏览器viewport，短内容收缩、设置长内容达到上限可滚动；属于受控浏览器，不是Windows截图。
- Windows x64 MSVC release和NSIS构建完成。独立解包验证PE为AMD64/Windows GUI；主程序与release仅差Tauri三字节包类型标记，12项资源匹配源文件；95项构建输入与当前XNook文件一致。

日志和截图保存在 [本轮证据目录](evidence/parity-0.3.0/)。核心测试数据与原生边界均隔离，不读写用户真实笔记/日历/注册表。

## 剩余边界

1. Windows实机安装、网易云/QQ音乐的精确版本与SMTC能力、倍速、文件拖入/拖出/剪贴板、托盘焦点、双向切换、DPI/多屏/IME尚未验证。目标平台实测状态保持false。
2. 按用户选择保留本地ICS，未接入账户日历；VTODO不导入，提醒为声音、不唤醒休眠电脑。
3. Windows尺寸范围仍是普通药丸180px起、歌词200px起、面板360px起；Mac的更极窄范围和逐像素外观尚未对齐，需要专门紧凑布局。
4. 同曲时长轻微漂移仍以精确时长键重新确认歌词；暂未复制Mac的模糊时长复用策略，避免回归此前8秒候选匹配边界。
5. 虚拟桌面驻留沿用Win11 24H2 build26100.2605+限制。安装器未签名、未发布，不表示完整Mac/Windows实机对齐。

实机操作与失败反馈格式见 [验收清单](windows-test-checklist.md)。
