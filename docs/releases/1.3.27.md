# X Nook v1.3.27 — 概览待办入口独立开关

日期：2026-10-27

本版修复了概览底部“待办 0”无法独立隐藏的问题。

## 新增与修复

- 新增了 **在概览显示待办入口** 开关，在 **设置 → 显示 → NookFlow** 中调整，也可直接搜索 **待办入口**。
- 关闭后移除了概览底部的待办按钮和占位，并同步收起已展开的待办收件箱。
- 保留了待办数据、布局、任务组件内部的入口，以及已保存的开关选择。

为兼容已有使用习惯，开关默认开启；如果你已经在本机修复版中关闭，升级后会继续保持关闭。该入口仅在“当前任务”和“最近任务”组件均隐藏时出现。

本版基于 v1.3.26，继续保留布局方案、媒体氛围、双岛联动与软件授权功能。

## 验证与安装包

相关 42 项检查全部通过，覆盖入口开关切换、空与非空待办、组件显隐、中英文设置搜索，以及原布局和待办数据保留；关闭入口后离屏面板高度减少 32pt。本机修复版已确认入口消失、新开关关闭，其他配置恢复。

发布前完整回归：XNook 1203 项（1108 通过、95 条件跳过），授权核心 17 项（16 通过、1 条件跳过），均为零失败；严格签名、Hardened Runtime、正式授权公钥、DMG 校验与只读挂载后逐文件及权限一致性均通过。

安装包面向 Apple Silicon **arm64**，最低 macOS **14**，沿用 **ad-hoc 签名与 Hardened Runtime**，未使用 Developer ID 或 Apple 公证。

构建、回归与安装包校验记录见 [发行验证](https://github.com/Meteorkid/XNook/blob/v1.3.27/docs/releases/verification-1.3.27.json)及[源码哈希](https://github.com/Meteorkid/XNook/blob/v1.3.27/docs/releases/source-hashes-1.3.27.json)。本机验收使用此前安装的同源修复版，正式发行包的签名与文件一致性另行校验。
