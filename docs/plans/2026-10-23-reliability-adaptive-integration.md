# 最新主线可靠性修复与面板适配

基线：`64853d09ab10cf4bb996f534fe3550c2de976903`。范围：macOS，独立工作区；保留最新主线已有功能。

## 1. 迁移与历史保留

- 迁移只复制经过验证的旧记录，不删除旧偏好键。旧键是迁移时的回退快照，不是与新版持续同步的数据镜像。
- 已有目标不覆盖，损坏源/目标和失败写入进入现有只读错误状态；使用两个临时 suite 验证迁移、幂等、失败重试。
- 移除历史超过200条时的持久化截断。概览继续显示最近几条，全部历史沿用 LazyVStack，旧任务及链接仍可查看、编辑。
- 选择最小修复，不引入多文件归档事务。全量历史编码的长期性能优化另行处理；本轮首先消除静默删除。

## 2. 书签验证

- 去掉“任何书签创建异常都跳过”的处理，不能把功能错误伪装成宿主权限不足。
- 用带对应签名权限的隔离测试宿主或独立验证进程，验证创建书签、跨进程重新读取、GIF预算拒绝。
- 仅使用临时文件与测试宿主，不触碰已安装正式应用、用户文件或系统权限设置。

## 3. 面板适配

- 在主线 ExpandedPanelView 上整合；保留工具导航、详情页、键盘操作、任务链接、玻璃背景、封面配色、刘海避让与动效。
- 概览先显示组件，最近/当前任务在组件之后。默认自动高度，手动200pt保留为可选上限。
- 首选宽度800pt时三组件一排，四组件2×2；窄屏换行；组件按自然内容高度测量，屏幕不足时正文滚动、标题固定。
- 布局测量带宽度校验并过滤无效值；换列保持组件身份，避免笔记编辑状态被重建；屏幕变化同步内容与原生窗口约束。
