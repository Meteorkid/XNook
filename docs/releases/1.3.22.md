# X Nook v1.3.22

日期：2026-10-25

本版让媒体、日历、笔记和文件详情页左上角始终显示带文字的“概览”按钮，点击即可回到组件概览。窄窗口会为按钮文字和物理刘海留出空间，离开笔记时也会先保存当前编辑。

本版同时收录了 v1.3.21 发布后已提交、已进入本机候选的界面与功能整合，包括横向媒体卡片、背景预设、待办收件箱、任务资料、歌词工具和播放进度定位。以下更新均以公开的 [v1.3.21](1.3.21.md) 为比较基线。

## 详情页返回概览

- 媒体、日历、笔记和文件详情页左上角改为固定的“概览”按钮，窄窗口不再只显示当前工具图标或需要展开菜单才能返回。
- 按钮保留完整文字，标题栏两侧空间不足时整体移到物理刘海下方，避免遮挡设置和关闭按钮。
- 点击“概览”后窗口继续展开，恢复组件概览并保留当前任务、保存的布局和各组件数据。
- 离开正在编辑的笔记前先保存，保存失败时继续留在详情页，避免未保存内容被导航带走。
- 保留了布局编辑期间的导航限制和原有网页链接编辑保护。

## 概览布局与外观

- 媒体卡片改为横向封面与曲目信息布局，播放按钮沿用封面配色，详情页提供更完整的曲目信息、歌词和播放进度。
- 默认概览按启用组件数量调整，三个主组件并排、四个主组件分为两行，当前任务与最近任务位于组件下方。
- 默认空态按内容收紧高度，未播放媒体、空文件托盘和空任务保留直接操作入口，已有手动保存的布局继续使用原位置与尺寸。
- 日历概览突出下一项安排，完整日程保留在详情页，笔记和文件概览也保留进入完整列表的入口。
- 修复了退出布局编辑后窗口高度残留的问题，取消编辑后即可按正常内容收缩。
- 增加了跟随外观、纯黑、浅色和液态玻璃四种岛背景预设，玻璃深浅可在 50%–100% 之间调整。
- 岛背景可以独立于应用和设置窗口外观选择，系统不支持玻璃或启用“减少透明度”时显示回退说明并使用纯色背景。
- 优化了与 XIsland 的显示交接，切换后静止鼠标不再被当作新的悬停进入，减少窗口尺寸跳变和重复切换引起的错误隐藏。

## 媒体与歌词

- 为具有有效曲目身份、时长和播放位置的 Apple Music／Spotify 增加了进度定位，拖动时预览目标位置，释放后提交并以播放器回读结果更新进度。
- 修复了 AppleScript 已成功执行定位却被误判为失败的问题，定位过程保留播放器原有暂停状态。
- 增加了歌词状态说明、跳过缓存的重试入口和全局 ±5 秒偏移调整，方便处理延迟或匹配不理想的歌词。
- 改进了迟到曲目时长的复核、歌词候选缓存和旧请求隔离，切歌后较早请求的结果不会覆盖当前曲目。
- 补齐了 Spotify 封面下载的超时与体积限制，以及异常媒体时间值的显示保护。

## NookFlow 待办、任务资料与提示

- 增加了待办收件箱，支持手工添加、受限 JSON 导入、重复项识别和从待办开始任务。
- 补齐了收件箱初始化恢复和失败重试，交接中断后保留原始输入，重复开始能够对应回已有任务。
- 补齐了当前及历史任务的资料管理，支持笔记重新关联、文件替换和网页链接操作，并在保存失败时保留草稿。
- 增加了任务时间预算、绝对到期时间和到时提示，历史任务的预算保留为只读记录。
- 补齐了任务结束、预算到时和可选日历提醒的活动提示，提示会去重，并遵守静默时段、编辑和模态窗口等状态。
- 增加了可选的 Claude Stop 事件接入及配置复制入口，用户需自行启用并配置客户端，应用不会自动改写已有 hook。

活动提示总开关沿用开启默认值，日历文字提醒与 Claude 来源默认关闭；Claude Stop 表示一次响应结束，不代表整个工作任务已经成功。

## 设置与可靠性

- 增加了中英文设置搜索，点击结果会定位并高亮实际控件，权限页可查看和刷新当前状态。
- 补齐了笔记创建、切换和关闭时的保存失败保护，以及明确选择“不保存退出”时的关闭流程。
- 改进了文件托盘批次保存和 GIF 后台导入校验，并隔离过期播放回调，减少部分写入或旧结果覆盖当前状态的情况。
- 修复了设置窗口的控制器绑定，补齐了睡眠、关闭和窗口销毁时的轮询及迟到回调处理。
- 增加了全局快捷唤出的设置、录制、冲突检查和清除入口，默认不分配组合键；真实按键触发仍有已知问题，详见下方验证边界。

内部同时补充了上述能力的状态机、存储、原生控件与布局回归测试。

## 升级与数据保留

升级后可以直接使用现有笔记、托盘、任务、历史记录和保存的网格布局，无需主动恢复默认。默认空态的高度调整只作用于符合自动适配条件的默认排列，不回写用户手动保存的尺寸。

本版保留 v1.3.21 已有的组件标题拖动、右下角缩放、布局保存／取消／恢复默认流程。网页链接标题仍由用户填写；另一工作树中尚未提交的网页标题获取功能未纳入本版。

## 安装包与验证边界

- 目标安装包为 `XNook-1.3.22.dmg`，面向 Apple Silicon（arm64），最低系统要求为 macOS 14。
- 发行沿用 ad-hoc 本地签名，未使用 Developer ID 签名或 Apple 公证。
- DMG SHA-256：`ddf7855a0e69fbb833fe4d8a8696302fa6f0f97a0f068d7c8da4078c1e896920`。
- 全局快捷唤出的设置录制、注册、重启保留和清除已验证，但此前本机物理按键触发无反应；已按用户要求清除临时组合并结束该项排查，本版不将它列为已修复或验收通过。
- Spotify 实际播放器定位、真实 Claude 客户端链路、VoiceOver、多屏及逐帧动画效果未由本轮概览按钮专项验收覆盖。
- 本轮日志仍保留两条既有测试事件泵附近的负尺寸警告，已检查的按钮几何和点击结果正常，尚未定位该警告来源。

## 版本来源

本版功能候选以 `e7830bd` 为基线；公开 v1.3.21 标签对应 `de05bc1`，是该候选的祖先。本机此前已安装的功能候选对应 `78e1c73`，其后至 `e7830bd` 仅新增及补充安装验收文档，生产源码一致。

因此，从已安装功能候选更新时保留既有能力，并增加本次详情页概览按钮修复；从公开 v1.3.21 更新时，也会获得本说明列出的此前未公开发行的整合功能。

发行包验证摘要见 [verification-1.3.22.json](verification-1.3.22.json)。
