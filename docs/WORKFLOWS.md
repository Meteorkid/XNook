# XNook 工作流与验证指南

## 运行

需要 macOS 14+、已完成初始化的 Xcode 15+。

```sh
./build-app.sh
open '.build/X Nook.app'
```

点击药丸或双指下滑展开。悬停展开默认关闭，可在设置中开启。顶部“概览”显示任务与常用工具；选择工具标签进入完整详情，窄面板改用下拉导航。面板宽度变化时自动调整列数，最大高度只限制视口，内容仍可滚动访问。

## 操作流程

### 笔记

1. 在概览点击新建或“查看全部”，也可进入“笔记”标签。
2. 详情搜索同时匹配标题和正文；点击任意笔记打开完整编辑器。
3. 标题和正文自动保存，完成或切换工具时会刷新待保存内容。
4. 删除后可撤销最近一次删除，恢复原位置和最新草稿。
5. 在编辑器中选择导出 Markdown 或 TXT，保存对话框由用户决定目标位置。两种格式都保留原文，TXT 不自动清除 Markdown 标记。

读取失败时保留原件并进入保护状态。通过警告图标可重试，或先保留原件副本再恢复使用。保存失败会保留草稿；退出时默认返回，只有明确选择“不保存并退出”才放弃未保存内容。

### 日历

第一次使用时点击授权按钮；打开概览不会反复请求权限。概览优先展示今天尚未结束的日程，点击“查看全部”进入所选日期的完整列表。浏览其他日期时保留当天全部时间顺序。

系统日历变更、应用返回前台、跨日与时区变化会触发刷新。若正在浏览今天，跨日后跟随新的今天；浏览历史日期则保持选择。可从详情打开系统日历进行编辑。

### NookFlow

1. 在概览输入任务名称并开始，或点击日历事件的开始按钮。
2. 创建关联笔记后直接进入编辑器；已关联时点击按钮重新打开笔记。
3. 将资料拖入文件架，再关联到当前任务。新关联保存独立文件引用。
4. 结束任务后，从最近任务或全部历史打开详情，重新查看笔记和文件。

清理文件架不会删除新任务中保存的文件引用。旧任务只有文件 ID 时，仍通过文件架尝试打开；旧引用已不在文件架或原文件不可用时会显示提示，不删除历史记录。任务历史读取失败时禁止覆盖原件，修复存储后可以重新读取。

## 键盘与动效

快捷键作用于已经展开并获得键盘焦点的面板，不是系统全局快捷键。

| 快捷键 | 行为 |
| --- | --- |
| ⌘0 | 返回概览 |
| ⌘1 / ⌘2 / ⌘3 / ⌘4 | 媒体 / 日历 / 笔记 / 文件架（已启用的工具） |
| ⌘N | 新建笔记并进入详情 |
| ⌘S | 保存当前笔记，保持编辑器打开 |
| Esc | 详情返回概览；概览收起 |
| Tab / Shift-Tab | 按系统键盘导航设置移动控件焦点 |

⌘Z 保留给文字编辑器的撤销；删除笔记用界面中的撤销按钮恢复。显式打开面板时允许键盘操作，悬停展开不主动抢走其他应用的键盘焦点。展开面板中的拖动交给内容控件，只有收起药丸支持拖动窗口。

应用设置或系统辅助功能中的“减少动态效果”任一开启时，停止装饰动画与文字滚动。长歌词仍可通过悬停提示读取全文。

## 验证

```sh
swift test
XNOOK_RENDER_UI=1 swift test --filter 'WorkflowPreviewTests|NotchWindowInteractionTests'
XNOOK_BUILD_DMG=0 ./build-app.sh
codesign --verify --deep --strict '.build/X Nook.app'
git diff --check
```

普通测试使用临时目录、独立 UserDefaults suite、假书签和事件，不修改真实业务数据。带 `XNOOK_RENDER_UI=1` 的验证需要 WindowServer，用隐藏窗口渲染隔离样例，不激活真实应用。截图输出到 `/tmp/xnook-workflow-ui/`，涵盖 800pt / 160pt 概览、笔记列表与编辑、日历详情和历史区域。

人工检查重点：160pt 窄面板仍能滚动导航和内容；长标题不覆盖操作；笔记拖选与文件拖出不移动整个面板；开启减少动态效果后 GIF、果冻、磁吸和跑马灯停止；关联资料在结束任务和应用重启后仍可打开。

### 仅命令行工具的构建

Command Line Tools 不带 Xcode 的预览宏插件，可以显式关闭编译期预览声明；这不影响正式界面代码，也不永久修改工具链配置：

```sh
DEVELOPER_DIR=/Library/Developer/CommandLineTools \
  ./build-app.sh -Xswiftc -DXNOOK_DISABLE_PREVIEWS
```

Xcode 中的预览默认保持启用。完整 XCTest 验证仍需要含 XCTest 的 Xcode 工具链；如果 Xcode 提示许可尚未确认，请由使用者打开 Xcode 查看并完成初始化后再运行测试。

## 常见问题

- **历史文件打不开**：重新连接磁盘或恢复文件位置。旧记录没有独立书签时还需要文件架中的原引用。
- **日历空白**：区分未授权、未选择日历、当天没有日程以及当天全部已结束；按界面提示处理。
- **笔记只读**：原始存储未能安全读取。先重试，必要时使用保留原件副本的恢复入口，勿删除原文件进行测试。
- **快捷键没有响应**：先点击展开面板，使其获得键盘焦点；工具快捷键只选择已启用工具。
- **画面超出最大高度**：在内容区域滚动，或在设置中提高面板最大高度。
