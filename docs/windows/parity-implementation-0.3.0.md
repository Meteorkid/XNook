# Windows 0.3.0 工作流对齐

2026-10-17。用户再次授权自主对齐 Mac 剩余功能、实现并验证。基准是当前 Sources 中实际可触达的用户入口；Mac 并行修改保留，初始 81 个源文件/测试哈希已记录。Windows 0.2.0 测试包保留。

## 本轮范围与设计

1. 任务与笔记：最近任务之外提供全部历史和详情；概览直接开始/结束、关联资料、新建/打开最近笔记。空标题采用本地化默认名。恢复已删除笔记后重绑当前任务引用，避免重复恢复；历史正文快照保持独立。快捷键忽略重复按下。
2. 日历概览：显示所选日的两项日程及全部入口，提供紧凑日期选择。今天过滤已结束，过去日期保留完整；详情标记进行中/已结束，用稳定来源色区分本地 ICS；跨日标记包含实际重叠日期，午夜结束不污染次日。
3. 音乐：概览直接控制所选会话；默认波形跟随播放且遵守减少动态效果。同曲歌词短重试耗尽后持续有限退避，切曲/关闭取消；真实播放倍速透传用于歌词插值，候选匹配仍保留精确时长。
4. 文件：逐项刷新可访问状态和普通文件大小；一个文件失败不影响其他项，保留失效引用和任务快照。增加刷新/重试入口，目录不递归扫描。
5. 浮岛与系统：收起态横向拖动、向下拖动展开、拖后抑制点击；展开后的横滚只操作内容。药丸右键设置/安全退出，托盘设置/检查更新先协调显示权。展开高度以设置为上限按自然内容收缩。

仍用 v1 存储，新增行为尽量使用现有字段；实时文件状态和浏览页码不写进用户数据。每项核心逻辑补回归。前端主集成由 root 负责，领域/键盘、日历/歌词、原生/手势由三个独立 worker 分文件并行完成。

## 取舍

沿用 Tauri/Rust/TypeScript，修补当前实现；没有理由重构跨平台核心或复制 Mac 系统 API。保留已有 Windows 能力（播放器手选、历史笔记快照、展开标题栏拖动），不会为表面相同删掉可用操作。

Mac 极窄尺寸需独立紧凑布局；本轮保持 Windows 已验证的最小尺寸范围，避免只放宽数字后裁切内容。账户日历继续按用户选择使用 ICS，不加入未配置账号。Mac 未接线的音量、日历增删/筛选不当成已交付功能。

## 验证顺序

纯逻辑与 Rust 测试 → 浏览器真实界面加受控原生边界 → 独立复核 → Windows x64 release/NSIS 构建 → 独立解包、构建输入及 ZIP 哈希校验。保持配套 XIsland 联动；其并行版本只有在完整包和冻结输入确认后纳入交付。

Windows 音乐客户端、资源管理器拖放、托盘/显示权、DPI/多屏/IME仍需 Windows 实机验收。没有用户授权不提交、推送或发布。
