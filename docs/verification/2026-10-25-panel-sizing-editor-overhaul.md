# 面板高度与布局编辑：实现和验证

日期：2026-10-25。本页记录发布前独立候选的实现与验证身份；后续发行说明见 [v1.3.23](../releases/1.3.23.md)。

## 本轮结果

- 媒体详情切换后，父级导航/宽度回调复核完整测量上下文，只丢弃过期测量。先到达的新高度不再被清掉，从而避免长期停留在 400pt 回退高度。
- 设置 → 显示 → 面板尺寸中，宽度与高度独立。展开高度可选“自动贴合内容”或“自定义高度上限”；内容少仍收紧，超限滚动。保留 `panelBaseHeight` 数值和默认 200，新 `panelHeightMode` 未设置时只读兼容旧 `panelAutoSize` 行为。
- 编辑工具栏及说明固定在画布上方，滚动组件时仍可查看和保存。单击选中、直接拖标题移动、拖角缩放；窄窗口明确说明重排和竖向缩放规则，无需双击或长按。
- 提供选中描边、拖动条、尺寸状态、清楚的缩放把手和隐藏组件恢复入口。主要组件显示只读预览，任务组件使用摘要以避免覆盖条叠字；编辑时禁用组件原操作。
- 没有修改时显示“完成”，退出不写入布局；修改后显示“未保存更改／保存布局”。保留取消、外部修改冲突与存储异常保护。
- 保留 1.3.22 的直接“概览”返回入口。正常宽度的详情页也能进入布局；160/200pt 极窄详情优先保留概览、设置和关闭，布局仍可从设置进入。
- 包含上一轮按钮悬停修复：固定命中区，轻微放大/上移，无擦除重绘。

## 使用入口

1. 面板顶部选择“编辑布局”，或设置 → 显示 → Widget 选择 → 打开布局编辑器。
2. 单击组件选中；拖标题移动，拖右下角缩放，也可用上方尺寸和前后移动按钮。
3. 在“已隐藏”中点击组件可找回；改动保存后生效，取消保持原布局。
4. 面板整体高度在设置 → 显示 → 面板尺寸调整，不与“组件高度”混为一项。
