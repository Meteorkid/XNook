# X Nook v1.3.28 — 授权状态与激活体验修复

日期：2026-10-27

本版修复解绑、网络请求取消和临时安全存储故障后的授权状态，并统一激活码与使用期限的中英文文案。建议使用软件授权功能的用户更新。

## 授权与设备管理

- 服务器已确认设备授权无效时，客户端立即停止接受旧租约，重启后也保留这一状态。
- 服务器解绑成功后立即停用本机，本地凭据保存失败也不会继续显示已激活。
- 钥匙串读取或写入短暂失败后可重试恢复，不需要为此清除原授权，也不会用旧缓存恢复已经确认的撤销状态。
- 退出过程会取消尚未完成的激活与验证请求，迟到响应不会重新激活或写入新凭据。
- 旧版离线激活码的迁移提示和空码错误会保留到界面上，页面刷新不再清空原因；成功验证后会清除旧错误。

授权协议、现有凭据格式、三设备限制和最长七天离线规则均保持不变。

## 激活界面

- 将正常界面统一为 **激活码、一个月、一年、永久**，英文为 **Activation code、1 month、1 year、Lifetime**。
- 明确了购买或管理员赠送后在官网账户查看激活码的步骤。
- 保留了试用与付费授权的区别，试用状态不会显示付费设备解绑入口。

## 升级兼容

保留了 1.3.27 新增的 **在概览显示待办入口** 开关及已有开关状态，也保留布局方案、媒体氛围、双岛联动、任务、笔记与文件托盘。无需重置配置或清空内容。

本轮新增了 26 个授权反例与边界测试，覆盖离线期限、冷重启与时钟变化、错误产品或设备、取消与迟到响应、临时存储恢复、常驻与模拟唤醒锁定，以及保存失败后的笔记导出。授权定向测试在 Debug 和 Release 构建均通过；合并 1.3.27 后再次完整回归：**XNook 1215 项，1120 通过、95 条件跳过、0 失败；共享授权核心 31 项全部通过**。
