# XNook 完整桌面工作流

## 目标

依据用户要求继续制定并执行终极目标，本轮交付完整可用的核心流程：记录与找回笔记、查看完整日程、开始任务并在历史中重新打开资料。主面板提供概览和单工具详情，窄面板与长内容均有可达入口。保留第一轮数据保护和现有用户设置，不自动提交 Git。

## 设计

- 笔记：概览显示最近记录，详情显示全部与搜索；支持重命名、删除后撤销、Markdown/纯文本导出。沿用文件存储与原件保护；跨任务打开笔记时从最新内存状态读取。
- 日历：当前日期优先显示进行中和未来事件，并提供完整当天列表；监听 EventKit 变化、回到前台和跨日，刷新授权与筛选；授权失败提供操作入口。测试不请求用户权限或读真实日历。
- NookFlow：可手动开始任务；已关联笔记可直接打开；历史详情显示全部关联信息并允许打开。文件快照增加可选 bookmark，旧记录通过原文件架 ID 尝试查找；不可用时明确反馈，不丢弃历史。损坏会话存储禁止覆盖。
- 面板：顶部概览/工具标签是真实导航；概览按宽度排布，详情拥有完整宽度，内容超出上限时滚动。按内容测量高度，替代“横向组件数量乘以纵向高度”的估算。禁用组件后的导航回退可预测；无启用组件时仍可开始和回看任务。
- 键盘与动效：Esc 返回概览/收起，工具导航支持快捷键与焦点；“减少动态效果”结合系统偏好，统一约束弹簧、磁吸、GIF 与滚动文字。编辑和弹出操作期间避免意外收起。

## 数据影响与恢复

不改笔记和文件架现有记录格式；任务文件引用仅添加可选字段，旧 JSON 可继续解码，无需批量迁移。任何损坏存储不能被新默认内容覆盖，回滚代码时旧版会忽略新增可选字段。不会在验收中修改用户真实存储或日历。

## 实施分工

笔记、日历、NookFlow 各自修改自己的 Manager/View/测试与独立 L10n 扩展；主代理维护 NotchContentView、尺寸/动效/键盘集成与最终验收。保留已有未提交改动，不做大范围架构重写。

## 验收标准

1. 超过 4 条笔记可全部找到，搜索、重命名、删除撤销、导出不丢内容，原异常存储保护测试保持通过。
2. 超过 2 条日程可全部查看，已结束日程不挤掉概览中的下一项；刷新和授权变化有隔离测试。
3. 手动开始 → 关联笔记/文件 → 结束 → 历史详情 → 重开资料可完成；旧记录和不可用资源都有明确处理。
4. 160pt 窄面板和默认宽度下均可导航与滚动；长文本不遮挡操作；减少动态效果真正停止装饰动效。
5. 全量 XCTest、Release 打包、签名与差异检查通过；使用隔离预览进行可行的 UI 检查。未能实测的外部日历、多屏和性能指标明确记录。
