# X Nook v1.3.24 — 布局方案、媒体氛围与双岛联动

日期：2026-10-27

本版加入可保存的布局方案和封面氛围效果，并整合 X Nook 与 X Island 的连续预览、提醒让位和按钮反馈修复。

## 布局方案

- 新增了标准三组件、专注任务、轻量媒体三套内置布局，并用缩略图展示组件排列。
- 新增了“自定义布局 1、2…”的另存功能，支持重命名、更新和删除。
- 为未保存草稿增加了切换确认，应用方案时也会检查其他窗口的同期修改。
- 让内置方案按内容收拢空态高度，并修正任务与笔记并排时的自动宽度计算。
- 保留了用户手动调整的组件尺寸，以及旧布局、笔记、文件和任务数据。

在设置中搜索 **布局方案** 可直接选择和管理方案；在 **编辑布局 → 布局方案** 中选择时，方案会先载入草稿，点击保存后生效。

## 媒体氛围与按钮

- 新增了 **关闭、封面柔光、动态模糊** 三档效果，默认使用封面柔光。
- 将封面色彩限制在媒体卡片背景内，保留横向封面、文字和播放按钮的位置。
- 让动态背景在暂停、隐藏或减少动态时停止流动，重新播放时延续原有位置。
- 将设置、关闭和媒体主按钮统一为轻微缩放反馈，移除了图标擦除、闪黑和上浮位移。

在设置中搜索 **媒体氛围** 可切换效果。动态模式采用低速背景流动，不改变播放内容、歌词或窗口测量。

## 双岛联动

- 新增了收起状态下的双指连续双页预览、松手确认和短滑回弹。
- 改善了共享边界与宽高过渡，以及快速反向、超时、取消和迟到回复的处理。
- 修复了交接时先恢复旧内容再隐藏造成的闪回，并避免背景和内容重复启动尺寸动画。
- 增加了提醒优先显示保护，X Island 的完成、审批或提问提醒出现后，过时请求不能再抢回界面。
- 保留了对端未运行、版本不支持或未准备好时的安全启动和普通切换。

在 **设置 → 联动** 开启双指横滑切换。连续预览要求两款应用已运行、支持该协议并处于兼容的收起状态；不满足时仍可普通切换。任务提醒开关由 X Island 管理，XNook不替用户批准权限或回答问题。

## 兼容与验证

升级保留现有配置和用户资料；旧自定义布局继续使用原有高度语义。应用与系统的减少动态设置均保留。软件授权模块、其他工作区尚未整合的网页标题功能及Windows版不属于本次发布范围。

发行树完整回归 **1197 项：1192 通过、5 条件跳过、0 失败**，包含原生离屏渲染及跨进程身份校验。产品源码与已验收的本机候选一致。

本轮已在本机验证三套预设、方案保存/重命名/更新/删除、草稿保护、三档媒体背景、减少动态冻结、设置与关闭及双向切换，测试后恢复原配置和数据。实际FPS、物理触控板半程手感及真实客户端提醒端到端验收仍有边界，自动化测试不替代这些结果。详细测试统计与安装包校验见 [发行验证](https://github.com/Meteorkid/XNook/blob/main/docs/releases/verification-1.3.24.json)。
