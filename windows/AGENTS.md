# Windows XNook

- 本项目是 XNook 的独立 Windows 客户端。保留根目录现有 macOS 源码及未提交修改。
- 技术栈为 TypeScript/Vite 与 Rust/Tauri 2。领域逻辑不得依赖 DOM；系统操作放入原生层。
- 首版日历由用户明确选择本地 .ics 导入；不能用样例冒充系统音乐、日历或双应用联动。
- XNook 与 XIsland 共用版本化的联动协议：对方确认显示后当前窗口才隐藏，失败保留当前窗口。
- 新增依赖只安装在项目目录，不修改全局工具、PATH 或真实 macOS 应用配置。
- 核心行为必须有回归测试；分别记录前端检查、原生测试、Windows 编译和 Windows 实机验收。
- 不自动提交、推送或发布。项目完成后由用户决定是否提交。
