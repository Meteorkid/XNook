# X Nook v1.3.23

日期：2026-10-25

本版集中改善面板高度与布局编辑：减少详情页多余留白，让高度设置、组件选择、拖动、缩放和保存更容易理解。

## 面板高度

- 修复了切换详情页或改变宽度后，正确的内容高度被后续回调清掉、窗口停在默认高度的问题。
- 新增了独立的“展开高度”模式，位置为 **设置 → 显示 → 面板尺寸**。
- “自动贴合内容”随当前页面收紧；“自定义高度上限”限制最大展开高度，内容较少时仍收紧，超出时滚动显示。
- 保留了已有高度数值、自定义高度上限默认 200pt 和旧配置行为，并将宽度适配与高度模式分开。

## 布局编辑

- 固定了编辑工具栏与操作说明，滚动画布时仍可查看提示、调整尺寸、保存和取消。
- 明确了操作方式：单击组件选中，直接拖标题移动，拖右下角缩放，无需双击或长按。
- 补充了窄窗口说明：组件自动换行，拖标题调整顺序，拖角调整高度，布局宽度在宽窗口显示。
- 增加了选中描边、清楚的拖动条和缩放把手，以及隐藏组件的恢复入口。
- 将宽度改为“1/3 宽、半宽、2/3 宽、整行”，高度改为带点数的档位名称，区别于面板整体高度。
- 增加了只读组件预览和未保存状态，编辑时不会触发组件原操作。
- 未修改时显示“完成”并直接退出，避免仅查看布局就写入自定义尺寸；实际修改仍在保存后生效。

## 按钮与兼容性

- 去掉了头部按钮悬停时先擦除再重绘的动画，设置、关闭和布局按钮改为轻微放大、上浮和按压反馈。
- 保留了 1.3.22 的“概览”返回按钮，并改善了极窄详情页中概览、设置和关闭的显示。
- 保留了已保存网格、组件开关、任务、笔记、托盘、横向封面、背景预设与双岛切换能力，无需重置布局。

本版仅包含本轮界面改动，尚未提交的网页标题获取功能未纳入。全局快捷唤出未作进一步改动，仍不列为已修复项。
